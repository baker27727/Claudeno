# Kom i gang med Claude Code

Claude Code er Anthropics offisielle CLI for agentbasert koding. I denne modulen
installerer du det og kjører din første interaktive økt.

## Installer

Den native installereren er den anbefalte metoden — den oppdaterer seg selv i
bakgrunnen, så du er alltid på nyeste versjon.

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Den kommandoen fungerer på macOS, Linux og WSL. Windows- og Homebrew-brukere har sine
egne installasjonskommandoer, og oppdaterer seg ikke automatisk på samme måte:

<PlatformTabs id="install" tabs={[
  { label: "Windows (PowerShell)", code: "irm https://claude.ai/install.ps1 | iex" },
  { label: "Windows (CMD)", code: "curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd" },
  { label: "Homebrew", code: "brew install --cask claude-code" },
]} />

<Callout type="note" title="Merk">
  Homebrew- og WinGet-installasjoner oppdaterer seg ikke automatisk — kjør
  `brew upgrade claude-code` (eller `winget upgrade Anthropic.ClaudeCode`) jevnlig for
  å holde deg oppdatert. Den native installereren håndterer dette for deg.
</Callout>

## Kjør din første økt

```bash
claude
```

Dette starter en interaktiv økt i prosjektmappen din. Skriv forespørselen din
på vanlig språk, eller `/help` for å liste tilgjengelige kommandoer.

## Din første forespørsel

Hopp over den trivielle "hello world"-testen — en første forespørsel som faktisk
forteller deg noe nyttig er:

```
Forklar hva dette prosjektet gjør og hvordan delene henger sammen.
```

Claude leser filene i prosjektet ditt for å svare, noe som samtidig fungerer som en
rask sjekk på at alt er riktig koblet sammen.

<Callout type="tip" title="Tips">
  Hvis noe med installasjonen virker feil, kjør `/doctor` inni en økt — den
  diagnostiserer Claude Code-installasjonen og innstillingene dine, og kan fikse
  rapporterte problemer for deg.
</Callout>

## Oppsummering

- Den native installereren (`curl ... | bash`) anbefales — den oppdaterer seg selv i bakgrunnen.
- Homebrew og WinGet fungerer også, men du må oppgradere dem selv.
- Å kjøre `claude` uten argumenter starter en interaktiv økt i gjeldende mappe.
- `/help` inni en økt lister opp alle kommandoer tilgjengelige for deg.

## Nytt i v2.1.220

Claude Code bruker nå Claude Opus 5 som standard, den raskeste Opus-modellen med 1M kontekstvindu. Raskemodus er tilgjengelig for Opus 5 og Opus 4.8 (Opus 4.7 støttes ikke lenger for raskemodus).

## Nytt i v2.1.221

Nytt i 2.1.221: Claude Code introduserer Focus-visningen (aktiveres med `Ctrl+Alt+F` eller kommandoen "Claude Code: Toggle Focus view"), som skjuler verktøyaktivitet bak en utvidbar oppsummering per tur med en live indikator for kjørende verktøy. Dette hjelper deg å holde arbeidsområdet fokusert samtidig som du opprettholder synlighet for hva Claude gjør i bakgrunnen.

## Nytt i v2.1.239

Nytt i 2.1.239: Kostnadsestimater (via `/cost`, statuslinje og `--max-budget-usd`) inkluderer nå 1,1× US-only-inference-premien for arbeidsområder med dataplassering. Windows-brukere kan nå bruke meldingsutveksling på tvers av økter med `SendMessage` og `ListAgents` for å kommunisere mellom Claude Code-økter på tvers av maskiner.
