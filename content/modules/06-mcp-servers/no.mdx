# MCP-tjenere

Model Context Protocol (MCP) er en åpen standard som kobler Claude Code til eksterne
verktøy, databaser og API-er — saksbehandlingssystemer, overvåkingsdashboard, CRM-er
og mer — slik at Claude kan handle direkte på dem i stedet for at du kopierer inn data
manuelt.

Claude Code kan koble til hundrevis av eksterne verktøy og datakilder gjennom [Model Context Protocol (MCP)](https://modelcontextprotocol.io/introduction), en åpen standard for AI-verktøyintegrasjoner. MCP-servere gir Claude Code tilgang til dine verktøy, databaser og API-er.

## Hva du kan gjøre med MCP

Med MCP-servere tilkoblet kan du be Claude Code om å:

* **Implementere funksjoner fra saksbehandlingssystemer**: "Legg til funksjonen beskrevet i JIRA-sak ENG-4521 og lag en PR på GitHub."
* **Analysere overvåkingsdata**: "Sjekk Sentry og Statsig for å kontrollere bruken av funksjonen beskrevet i ENG-4521."
* **Søk i databaser**: "Finn e-postadresser til 10 tilfeldige brukere som brukte funksjonen ENG-4521, basert på PostgreSQL-databasen vår."
* **Integrer designs**: "Oppdater standard e-postmalen vår basert på de nye Figma-designene som ble lagt ut på Slack"
* **Automatiser arbeidsflyter**: "Lag Gmail-utkast som inviterer disse 10 brukerne til en tilbakemeldingsøkt om den nye funksjonen."
* **Reager på eksterne hendelser**: En MCP-tjener kan også fungere som en kanal som pusher meldinger inn i økten din, slik at Claude reagerer på Telegram-meldinger, Discord-chatter eller webhook-hendelser mens du er borte.

## Installere MCP-servere

MCP-servere kan konfigureres på flere måter avhengig av dine behov:

### Alternativ 1: Legg til en ekstern HTTP-tjener

HTTP-servere er det anbefalte valget for tilkobling til eksterne MCP-servere. Dette er den mest bredt støttede transporten for skybaserte tjenester.

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

Du kan også sende autentiseringshoder:

```bash
claude mcp add --transport http secure-api https://api.example.com/mcp \
  --header "Authorization: Bearer your-token"
```

### Alternativ 2: Legg til en ekstern SSE-tjener

<Callout type="warning">
SSE-transporten (Server-Sent Events) er foreldet. Bruk HTTP-servere i stedet der det er mulig.
</Callout>

Noen tjenester eksponerer bare et SSE-endepunkt:

```bash
claude mcp add --transport sse asana https://mcp.asana.com/sse
```

### Alternativ 3: Legg til en lokal stdio-tjener

Stdio-servere kjører som lokale prosesser på maskinen din. De er ideelle for verktøy som trenger direkte systemtilgang eller tilpassede skript.

```bash
claude mcp add --transport stdio myserver -- npx server
```

**Viktig:** Bruk `--` (dobbelt bindestrek) for å skille Claudes alternativer fra tjenarkommandoen. Alt etter `--` sendes uendret til serveren.

Claude Code setter `CLAUDE_PROJECT_DIR` i tjenarens miljø til prosjektroten, slik at serveren din kan løse prosjektrelaterte stier.

### Alternativ 4: Legg til en ekstern WebSocket-tjener

WebSocket-servere opprettholder en vedvarende toveis forbindelse, som passer for eksterne MCP-servere som pusher hendelser til Claude uoppfordret:

```bash
claude mcp add-json events-server \
  '{"type":"ws","url":"wss://mcp.example.com/socket","headers":{"Authorization":"Bearer YOUR_TOKEN"}}'
```

## Valg av nivå (scope)

```bash
claude mcp add --transport http stripe --scope local https://mcp.stripe.com
```

`--scope` styrer hvem andre som ser denne tjeneren:

| Nivå | Lastes inn i | Delt med team | Lagret i |
| - | - | - | - |
| `local` (standard) | Kun gjeldende prosjekt | Nei | `~/.claude.json` |
| `project` | Kun gjeldende prosjekt | Ja, via versjonskontroll | `.mcp.json` i prosjektroten |
| `user` | Alle dine prosjekter | Nei | `~/.claude.json` |

<Callout type="mistake" title="Vanlig feil">
Å legge til en tjener med API-nøkkel med `--scope project` committer tilkoblingskonfigurasjonen der hele teamet ditt (og git-historikken) kan se den. Bruk `local`- eller `user`-nivå for alt som er sensitivt med tanke på legitimasjon.
</Callout>

### Prosjektnivå

Prosjektscope-servere muliggjør teamsamarbeid ved å lagre konfigurasjoner i en `.mcp.json`-fil i prosjektroten. Når du legger til en prosjektscope-tjener, oppretter eller oppdaterer Claude Code automatisk denne filen:

```json
{
  "mcpServers": {
    "shared-server": {
      "type": "http",
      "url": "https://example.com/mcp"
    }
  }
}
```

Sjekk `.mcp.json` inn i versjonskontroll slik at alle på teamet ditt får de samme MCP-verktøyene.

### Miljøvariabelutvidelse i `.mcp.json`

Claude Code støtter miljøvariabelutvidelse i `.mcp.json`-filer:

```json
{
  "mcpServers": {
    "api-server": {
      "type": "http",
      "url": "${API_BASE_URL:-https://api.example.com}/mcp",
      "headers": {
        "Authorization": "Bearer ${API_KEY}"
      }
    }
  }
}
```

Bruk `${VAR}` for å referere til en miljøvariabel, eller `${VAR:-default}` for å angi en standardverdi.

**Legitimasjonsvariablene som leses som tomme:** I en ekstern tjeners `url` og `headers` leser Claude Code legitimasjonsvariablene som `ANTHROPIC_API_KEY`, `AWS_BEARER_TOKEN_BEDROCK` og andre sensitive navn som tomme for å forhindre lekkasje av legitimasjon. Bruk dine egne variabelnavn i stedet.

## Administrere tilkoblinger

```
/mcp
```

`/mcp` åpner den interaktive listen over MCP-tjenertilkoblingene dine. Du kan:

* Kontrollere tjenerstatus med `✔ Connected`, `! Needs authentication` eller `✘ Failed to connect`
* Sende `reconnect <server>` for å koble til på nytt en som falt fra
* Bruke `enable`/`disable` med et tjenernavn (eller `all`) for å veksle tilkoblingsstatus
* Bruke `claude mcp list` for å liste alle servere fra kommandolinjen

## Autentiser med eksterne MCP-servere

Mange skybaserte MCP-servere krever autentisering via OAuth 2.0. Claude Code markerer en ekstern tjener som trenger autentisering når den svarer med `401 Unauthorized` eller `403 Forbidden`.

Åpne `/mcp` og velg en tjener for å fullføre OAuth-flyten. Når du fjerner en ekstern tjener, sletter Claude Code også OAuth-tokenene som ble lagret for den tjeneren.

## Deaktiver en tjener uten å fjerne den

Slå en tjener av i `/mcp`-panelet for å stoppe Claude Code fra å koble til den uten å miste konfigurasjonen. Claude Code viser fortsatt serveren i `/mcp`, merket som deaktivert.

## Finn og bygg MCP-servere

Bla gjennom gjennomgåtte koblinger i [Anthropic Directory](https://claude.ai/directory). Directory-koblinger bruker samme MCP-infrastruktur som Claude Code.

For å bygge din egen tjener, se [MCP-serverveiledningen](https://modelcontextprotocol.io/docs/develop/build-server) for protokollfundamenter og [Claude-koblingsdokumentasjonen](https://claude.com/docs/connectors/building) for autentisering, testing og kataloginnsendinser.

Du kan også la Claude bygge en tjener for deg med det offisielle `mcp-server-dev`-pluginet:

```
/plugin install mcp-server-dev@claude-plugins-official
/mcp-server-dev:build-mcp-server
```

Claude spør om brukstilfelle ditt og bygger en ekstern HTTP- eller lokal stdio-tjener.

## Praktiske eksempler

### Eksempel: Koble til GitHub for kodegjennomganger

GitHubs eksterne MCP-tjener autentiserer med et GitHub-personlig tilgangstoken. For å få ett, åpner du [GitHub-tokeninnstillingene](https://github.com/settings/personal-access-tokens) og genererer et nytt finkornet token med tilgang til repositoriene du vil at Claude skal jobbe med:

```bash
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \
  --header "Authorization: Bearer YOUR_GITHUB_PAT"
```

Arbeid deretter med GitHub:

```
Gjennomgå PR #456 og foreslå forbedringer
```

```
Lag en ny sak for feilen vi nettopp fant
```

### Eksempel: Spør PostgreSQL-databasen

DBHub er en MCP-tjener som kobler Claude til en relasjonsdatabase. Bruk en skrivebeskyttet databasebruker i tilkoblingsstrengen slik at spørringene Claude kjører ikke kan endre data:

```bash
claude mcp add --transport stdio db -- npx -y @bytebase/dbhub \
  --dsn "postgresql://readonly:pass@prod.db.com:5432/analytics"
```

Spør deretter databasen naturlig:

```
Hva er totale inntekter våre denne måneden?
```

```
Vis meg skjemaet for orders-tabellen
```

## Oppsummering

- `stdio` kjører lokalt; `http`/`sse`/`ws` kobler til en ekstern tjener.
- `claude mcp add --transport <type> <name> <url>` er den generelle formen for
  eksterne tjenere; stdio-tjenere legger til `-- <command>` på slutten.
- `--scope` avgjør om en tilkobling er privat (`local`), delt med teamet ditt
  (`project`), eller tilgjengelig overalt du jobber (`user`) — velg bevisst for alt
  med legitimasjon.
- `/mcp` administrerer tilkoblinger uten å forlate økten din.
