# Slash Commands

Inside an interactive session, commands starting with `/` control the session itself —
your context, your model, your history — rather than asking Claude to do something in
your code. A command is only recognized at the start of your message; anything after
it becomes an argument. When in doubt, this always works:

```bash
/help
```

Type `/` to see all available commands, or type `/` followed by letters to filter.

## Managing your context

Two commands sound similar but do very different things.

```bash
/clear
```

`/clear` starts a brand new conversation with completely empty context. The old
conversation isn't gone — it's just parked; you can reopen it later with `/resume`.
Aliases: `/reset`, `/new`.

```bash
/compact
```

`/compact` frees up space by **summarizing** the conversation so far, instead of
wiping it. You keep working in the same conversation, just with a lighter context
window.

<Callout type="tip" title="Tip">
  Use `/clear` when you're switching to a genuinely unrelated task. Use `/compact`
  when you're still working on the same thing but the conversation has gotten long.
</Callout>

## Continuing later

```bash
/resume
```

`/resume` reopens a past conversation by picking it from a list, including ones you
left behind with `/clear`. Alias: `/continue`. This is different from `-c`/`--continue`
at the CLI level (covered in [CLI Basics](/en/learn/cli-basics)), which always resumes
the *most recent* conversation without a picker.

## Switching models mid-session

```bash
/model
```

`/model` opens a picker to switch which Claude model the session uses, and saves your
choice as the default for new sessions. No need to restart Claude Code to try a
different model.

## Undoing a mistake

```bash
/rewind
```

`/rewind` steps back to an earlier point — in the code, in the conversation, or both.
It's the closest thing to a safety net for when a change went somewhere you didn't
want. Aliases: `/checkpoint`, `/undo`.

<Callout type="mistake" title="Common mistake">
  Reaching for `/clear` to "undo" a bad edit just loses your context — it doesn't
  touch the files Claude changed. Use `/rewind` to actually roll back code.
</Callout>

## More commands worth knowing

| Command | Purpose |
|---|---|
| `/permissions` | Manage allow/ask/deny rules for tools. Alias `/allowed-tools`. |
| `/mcp` | Connect to, list, or reconnect MCP servers. |

| `/effort` | Adjust effort level: `low` to `xhigh`, `max`, `ultracode`, or `auto`. |

| `/security-review` | Check the diff for security vulnerabilities. |
| `/memory` | Refine your project's `CLAUDE.md` memory file. |
| `/batch` | Decompose a large change into independent units and run each in parallel. |

| `/background` | Detach the current session to run as a background agent. Alias: `/bg`. |

## Workflows and skills

Some commands are bundled workflows or skills that fan work out across multiple subagents or provide specialized guidance:

| Command | Purpose |
|---|---|
| `/batch` | **[Skill]** Orchestrate large-scale changes across a codebase in parallel. |
| `/code-review` | **[Skill]** Review code for correctness bugs and cleanup opportunities. |
| `/deep-research` | **[Workflow]** Fan out web searches, fetch and cross-check sources, and synthesize a cited report. |
| `/design` | **[Skill]** Draft UI mockups, screen flows, landing pages, or posters as artboards. |
| `/dataviz` | **[Skill]** Design guidance for charts, graphs, and dashboards. |
| `/verify` | **[Skill]** Verify that code changes work correctly (invoke explicitly). |

## Key takeaways

- `/clear` wipes context and starts fresh; `/compact` summarizes without wiping.
- `/resume` reopens any past conversation by name or ID — nothing is truly lost.
- `/model` switches models without restarting the session.
- `/rewind` is the real "undo" for code changes, not `/clear`.
- `/effort` and `/advisor` customize how Claude approaches your task.
- `/code-review` runs as a background subagent, keeping your conversation focused.

## Related skills

A skill behaves like a slash command that can also trigger itself: `/name` works exactly like a custom command, but Claude also loads it automatically when your request matches its description. Learn how in [Skills & SKILL.md](/en/learn/skills/), or [browse the curated skills catalog](/en/skills/).
