## Oversikt

Claude Code akselererer forskningstilløp ved å automatisere analyse, syntese og rapportgenerering. Enten du gjennomfører litteraturgjennomgang, analyserer datasett, eller syntesiserer funn fra flere kilder, leser Claude Code dokumenter, trekker ut innsikt og genererer strukturerte sammenfattinger.

## Vanlige forskningstilløp

### Litteraturgjennomgang og syntese

Mat Claude Code flere forskningsmanus, artikler eller dokumenter. Den kan:
- Trekke ut sentrale funn og metodologier
- Identifisere felles temaer og motstridigheter
- Organisere sitater etter emne
- Generere merkede bibliografier

**Eksempel på arbeidsflyt:**
1. Last opp 5–10 manus om ditt forskningstema
2. Be Claude Code identifisere hovedforskningsspørsmål, metoder og konklusjoner
3. Be om en oppsummeringstabell som sammenligner metodologier og funn
4. Generer en strukturert disposisjon for litteraturgjennomgangen din

### Dataanalyse og visualisering

Claude Code integreres med datafiler for å:
- Parse CSV-, JSON- eller Excel-datasett
- Kjøre grunnleggende statistisk analyse
- Generere diagrammer og oppsummeringer
- Identifisere mønstre og avvik

**Tips:** Beskriv hva du leter etter før du laster opp—Claude Code reagerer bedre med kontekst.

### Rapportgenerering

Automatiser repeterende rapportering:
- Generer ledelsessammenfattinger fra råforskning
- Lag formaterte tabeller og figurer
- Organiser funn i publikasjonsklar seksjoner
- Kryssreferanse og sitere kilder automatisk

## Beste praksis

### 1. Gi klar kontekst
Før du sender inn dokumenter, forklar:
- Hva du forsker på
- Hvilke innsikter som betyr mest
- Hvordan utdataene vil bli brukt

### 2. Strukturer inndataene dine
- Grupper relaterte dokumenter sammen
- Bruk konsistent navngiving (f.eks. "studie_2024_emne.pdf")
- Gi metadata hvis tilgjengelig (publiseringsdato, forfatter, felt)

### 3. Iterativ foredling
Start med en bred forespørsel, deretter refiner:
1. Første pass: "Oppsummer hovedfunnene"
2. Andre pass: "Fokuser på metodologi og utvalgsstørrelse"
3. Tredje pass: "Trekk ut anbefalinger for fremtidig forskning"

### 4. Verifiser kritiske detaljer
Krysssjekk alltid:
- Statistikk og tall mot originalene
- Forfatternavn og publiseringsdatoer
- Direkte sitater og kilder

## Begrensninger å kjenne til

- **Dokumentlengde:** Fungerer best med forskningsutdrag; meget lange manus kan kreve deling
- **Proprietære format:** Hold deg til PDFer, TXT eller markdown
- **Sanntidsdata:** Kan ikke få tilgang til databaser eller live-nettersteder; bruk eksporterte data i stedet
- **Tolkningsnuanse:** Verifiser funn som krever domeneekspertise

## Rask start

1. **Samle kilder:** Samle PDFer, artikler eller datasett
2. **Innramme spørsmålet:** Skriv 2–3 setninger om hva du trenger
3. **Send til Claude Code:** Last opp filer og forespørselen din
4. **Gjennomgå utdata:** Kontroller nøyaktighet og refiner om nødvendig
5. **Eksporter/siter:** Bruk genererte sammenfattinger i arbeidet ditt

## Eksempel på spørsmål

- "Analyser disse 8 manuskriptene om maskinlæring innen helsevesen. Lag en sammenligningstabell av metodologier, utvalgsstørrelser og sentrale funn."
- "Trekk ut hovedforskningsspørsmål, hypoteser og konklusjoner fra denne datasettanalyseraporten."
- "Oppsummer begrensningene nevnt i disse studiene og foreslå områder for fremtidig forskning."
