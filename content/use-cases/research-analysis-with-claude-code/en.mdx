## Overview

Claude Code accelerates research workflows by automating analysis, synthesis, and report generation. Whether you're conducting literature reviews, analyzing datasets, or synthesizing findings across multiple sources, Claude Code reads documents, extracts insights, and generates structured summaries.

## Common Research Tasks

### Literature Review & Synthesis

Feed Claude Code multiple research papers, articles, or documents. It can:
- Extract key findings and methodologies
- Identify common themes and contradictions
- Organize citations by topic
- Generate annotated bibliographies

**Example workflow:**
1. Upload 5-10 papers on your research topic
2. Ask Claude Code to identify the main research questions, methods, and conclusions
3. Request a summary table comparing methodologies and findings
4. Generate a structured outline for your literature review

### Data Analysis & Visualization

Claude Code integrates with data files to:
- Parse CSV, JSON, or Excel datasets
- Run basic statistical analysis
- Generate charts and summaries
- Identify patterns and anomalies

**Tip:** Describe what you're looking for before uploading—Claude Code responds better with context.

### Report Generation

Automate repetitive reporting:
- Generate executive summaries from raw research
- Create formatted tables and figures
- Organize findings into publication-ready sections
- Cross-reference and cite sources automatically

## Best Practices

### 1. Provide Clear Context
Before submitting documents, explain:
- What you're researching
- What insights matter most
- How the output will be used

### 2. Structure Your Input
- Group related documents together
- Use consistent naming (e.g., "study_2024_topic.pdf")
- Provide metadata if available (publication date, author, field)

### 3. Iterative Refinement
Start with a broad request, then refine:
1. First pass: "Summarize the main findings"
2. Second pass: "Focus on methodology and sample size"
3. Third pass: "Extract recommendations for future research"

### 4. Verify Critical Details
Always cross-check:
- Statistics and numbers against originals
- Author names and publication dates
- Direct quotes and citations

## Limitations to Know

- **Document length:** Works best with research excerpts; very long papers may require splitting
- **Proprietary formats:** Stick with PDFs, TXT, or markdown
- **Real-time data:** Cannot access databases or live websites; use exported data instead
- **Interpretation nuance:** Verify findings that require domain expertise

## Quick Start

1. **Gather sources:** Collect PDFs, articles, or datasets
2. **Frame the question:** Write 2–3 sentences about what you need
3. **Submit to Claude Code:** Upload files and your request
4. **Review output:** Check accuracy and refine if needed
5. **Export/cite:** Use generated summaries in your work

## Example Prompts

- "Analyze these 8 papers on machine learning in healthcare. Create a comparison table of methodologies, sample sizes, and key findings."
- "Extract the main research questions, hypotheses, and conclusions from this dataset analysis report."
- "Summarize the limitations mentioned in these studies and suggest areas for future research."
