## Overview

Claude Code transforms SEO workflows by automating repetitive technical tasks and providing intelligent analysis. Whether you're optimizing content, auditing site structure, or implementing structured data, Claude can execute code directly on your codebase and development environment.

## Key SEO Tasks Claude Can Automate

### 1. Content Analysis & Optimization

Claude Code can:
- **Analyze page content** for keyword density, readability metrics, and semantic relevance
- **Generate title tags and meta descriptions** that balance keyword inclusion with click-through optimization
- **Identify content gaps** by comparing your content against competitor pages
- **Check heading hierarchy** (H1, H2, H3) to ensure proper semantic structure
- **Audit internal linking** patterns and suggest optimization opportunities

**Example workflow:**
```
1. Provide Claude with your page content
2. Specify target keywords and search intent
3. Claude generates optimized versions of title, description, and headings
4. Review suggestions and implement changes
```

### 2. Technical SEO Audits

Claude Code excels at examining your website's technical foundation:
- **Crawl URL structures** and identify redirect chains or broken internal links
- **Validate robots.txt and sitemap.xml** files for completeness and correctness
- **Check canonical tags** implementation and identify duplicate content issues
- **Audit response headers** (cache-control, ETag, compression)
- **Test page speed metrics** and suggest optimization targets
- **Verify mobile responsiveness** using viewport meta tags and CSS

**Common audits:**
- Identifying missing or duplicate canonical tags
- Checking robots.txt directives align with your indexing strategy
- Validating sitemap coverage and freshness
- Detecting and fixing HTTP/HTTPS mixed content issues

### 3. Structured Data Implementation

Structured data is crucial for search visibility and rich results. Claude can:
- **Generate JSON-LD schema markup** for articles, products, FAQs, and local business
- **Validate existing schema** against Google's requirements
- **Implement breadcrumb markup** for improved navigation display
- **Create FAQ schema** from your help documentation
- **Generate product schema** with pricing, availability, and reviews

**Quick start:**
Provide Claude with your page content and desired rich result type (article, product, local business), and it generates production-ready schema.

### 4. Keyword Research & Mapping

Claude can process and organize SEO data:
- **Analyze search volume and competition data** to prioritize keywords
- **Map keywords to existing content** and identify gaps
- **Group related keywords** into topic clusters
- **Generate content briefs** with keyword recommendations and search intent analysis
- **Create SEO-friendly URL structures** aligned with keyword targeting

### 5. Report Generation & Monitoring

Automate your SEO reporting:
- **Parse Google Search Console data** and generate executive summaries
- **Compare performance metrics** across date ranges
- **Track keyword ranking changes** and identify trends
- **Monitor Core Web Vitals** compliance and identify pages needing optimization
- **Generate audit reports** documenting issues and fixes

## Common SEO Use Cases

### Use Case 1: Optimize 404 Error Page
**Task:** Improve SEO value of 404 pages through proper redirects and internal linking
- Claude analyzes broken link patterns from server logs
- Generates 301 redirect mappings to relevant content
- Suggests internal links for the 404 page itself

**Task:** Add FAQ structured data to boost featured snippet visibility
- Provide Claude with your FAQ page content

## Best Practices for SEO with Claude Code

### 1. Provide Context
- Share your target audience and search intent
- Include competitor examples (when relevant)
- Specify your CMS platform or framework
- Mention any existing SEO guidelines

### 2. Think in Systems, Not One-Offs
- Apply optimizations across template pages, not just individual URLs
- Use Claude to create reusable schema templates
- Generate processes that can scale (e.g., automated reports)

### 3. Validate Before Publishing
- Test generated schema with Google's Rich Results Test
- Check page speed metrics before and after changes
- Use Search Console to monitor crawl errors post-implementation
- A/B test title/description variations when possible

### 4. Maintain Version Control
- Keep backups of original files before Claude-assisted changes
- Document all modifications for compliance and audits
- Review code changes carefully before production deployment

### 5. Balance Automation with Human Judgment
- Claude generates data-driven recommendations; you set SEO strategy
- Use Claude for heavy lifting (analysis, schema generation, report building)
- Reserve creative decisions for you (messaging, tone, unique positioning)
- Verify technical recommendations align with platform capabilities

## Troubleshooting Common Issues

**Issue: Generated schema isn't validating**
- Verify all required fields are included per Google's documentation
- Check JSON syntax for proper escaping of quotes
- Ensure date formats match ISO 8601 standard
- Test with Google's Rich Results Test tool

**Issue: Redirects aren't working properly**
- Confirm HTTP status code is 301 (permanent) not 302 (temporary)
- Check redirect chain length (avoid multiple hops)
- Verify destination URL returns 200 status code
- Clear CDN cache after implementing redirects

**Issue: Page speed scores haven't improved**
- Claude may identify optimization opportunities; actual improvements depend on your hosting
- Prioritize fixes by impact (images > JavaScript > CSS)
- Test on Core Web Vitals with real user monitoring
- Consider server-side improvements (compression, caching)
