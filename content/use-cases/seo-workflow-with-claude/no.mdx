# SEO-arbeidsflyt med Claude Code

Search Engine Optimization (SEO) er en kompleks prosess som involverer tekniske revisjoner, innholdsanalyse og kontinuerlig optimalisering. Claude Code kan automatisere mye av denne arbeidsflyten—lese nettstedsstrukturen din, analysere innhold og implementere forbedringer—alt mens du holder deg i editoren eller terminalen.

## Hvorfor Claude Code for SEO?

Claude Code utmerker seg ved SEO-oppgaver fordi det kan:

- **Lese hele kodebasen din** for å forstå nettstedsstruktur og identifisere optimaliseringsmuligheter
- **Kjøre kommandoer** for å kjøre SEO-analyseverktøy og integrasjoner
- **Skrive og endre filer** for å implementere tekniske SEO-forbedringer
- **Generere rapporter** med handlingsorienterte anbefalinger basert på industristandard
- **Integrere med APIer** for å hente data fra Google Search Console, Google Analytics eller SEO-verktøy fra tredjeparter

## Kjerne-SEO-optimaliseringsarbeidsflyt

### 1. Analyse av nettstedsstruktur

Start med å få Claude Code til å undersøke nettstedets struktur:

```
Analyser nettstedets struktur og lag en sitemaprapport. Se etter:
- URL-mønstre og hierarki
- Intern lenkestruktur
- Statisk vs. dynamisk innhold
- Indikasjoner på mobil responsivitet
```

Claude Code vil lese kodebasen din, identifisere sider og kartlegge nettstedsarkitekturen. Dette avslører muligheter for bedre crawlability og intern lenking.

### 2. Innholdsrevisjon

Få Claude Code til å undersøke innholdet ditt for SEO-problemer:

```
Revidér alle blogginnleggssider for SEO-samsvar:
- Tittelkoder (bør være 50-60 tegn)
- Metabeskrivelser (bør være 155-160 tegn)
- Overskriftshierarki (H1, H2, H3 struktur)
- Nøkkelordtilstedeværelse og -tetthet
- Fullstendighet av alt-tekst for bilder
```

Claude Code kan skanne innholdsfilene dine, identifisere hull og generere en rapport som viser hvilke sider som trenger optimalisering.

### 3. Implementering av teknisk SEO

La Claude Code implementere tekniske forbedringer:

```
Implementer følgende tekniske SEO-forbedringer:
1. Legg til XML-sitemapgenerering for alle sider
2. Lag robots.txt med passende direktiver
3. Legg til kanoniske tags til innholdsmaler
4. Implementer strukturerte data (Schema-merking) for artikler
5. Legg til metatags for sosial deling (Open Graph, Twitter Cards)
```

Claude Code kan:
- Generere sitemapfiler automatisk
- Skrive robots.txt som følger Googles anbefalinger
- Legge til kanoniske tags for å forhindre duplikatinnholdsproblemer
- Implementere JSON-LD strukturerte data
- Legge til Open Graph og Twitter Card metatags

### 4. Automatisert rapportgenerering

Få Claude Code til å lage omfattende SEO-rapporter:

```
Generer en detaljert SEO-revisjonrapport som inkluderer:
- Sammendraget av problemer som ble funnet
- Resultater av teknisk SEO-sjekkliste
- Innholdskvalitetsmålinger
- Vurdering av mobilbrukervennlighet
- Linkstrukturanalyse
- Prioriterte anbefalinger for neste trinn
Format som både HTML og PDF
```

## Praktisk eksempel: Komplett SEO-revisjonsskript

Her er en typisk arbeidsflyt du kan be Claude Code om å opprette:

```python
# seo_audit.py - Automatisert SEO-analyse
import os
import json
from pathlib import Path

def audit_seo_compliance():
    """Analysér nettsted for SEO-problemer"""
    
    # Skann alle innholdsfiler
    issues = []
    
    for markdown_file in Path('content').glob('**/*.md'):
        with open(markdown_file) as f:
            content = f.read()
        
        # Sjekk tittelkodlengde
        if 'title:' in content:
            title = content.split('title: ')[1].split('\n')[0]
            if len(title) < 30 or len(title) > 60:
                issues.append({
                    'file': str(markdown_file),
                    'issue': f'Tittelkode for lang: {len(title)} tegn',
                    'priority': 'high'
                })
        
        # Sjekk for metabeskrivelser
        if 'description:' not in content:
            issues.append({
                'file': str(markdown_file),
                'issue': 'Manglende metabeskrivelse',
                'priority': 'high'
            })
        
        # Sjekk overskriftsstruktur
        h1_count = content.count('# ')
        if h1_count != 1:
            issues.append({
                'file': str(markdown_file),
                'issue': f'Flere H1-tags ({h1_count} funnet)',
                'priority': 'medium'
            })
    
    return issues

if __name__ == '__main__':
    issues = audit_seo_compliance()
    print(json.dumps(issues, indent=2))
```

## Beste praksis med Claude Code

### 1. Del opp store revisjoner

Få Claude Code til å fokusere på spesifikke seksjoner for store nettssteder:

```
Revidér bare blogg-seksjonen:
- Analysér 50 nyeste innlegg
- Sjekk tittel- og beskrivelsesoptimalisering
- Generer forbedringsforslagene
- Prioriter rettinger etter impact
```

### 2. Automatisér repetitive oppgaver

Bruk Claude Code til å håndtere kjedelige optimaliseringsarbeid:

- **Generer sitemaps** automatisk når nytt innhold legges til
- **Legg til standard SEO-tags** på nye sider
- **Lag alt-tekstmaler** for bilder
- **Format URLer** i henhold til SEO-beste praksis

### 3. Integrer med Google-verktøy

Få Claude Code til å hente data fra Googles verktøy:

```
Hent data fra Google Search Console API:
- Få liste over sider med laveste gjennomsnittlig klikksats
- Identifisér forespørsler der vi rangerer 4-10 (optimaliseringsmuligheter)
- Eksportér toppytende nøkkelord
- Generer anbefalinger for hver enkelt
```

### 4. Overvåk og rapporter

Sett opp automatisert overvåking:

```
Lag en ukentlig SEO-helsekontroll:
- Sjekk alle sider for brutte metatags
- Verifiser at interne lenker fungerer
- Generer trendrapport i sammenligning med forrige uke
- Send sammendrag til interessenter
```

```
2. Analyserer hver side mot SEO-standarder
3. Foreslår og implementerer forbedringer
4. Genererer ukentlige resultatrapporter
5. Identifiserer innholdsmuligheter basert på søketrender
6. Anbefaler forbedringer av intern lenking
```

Claude Code kan kjøre denne agenten automatisk og gjøre kontinuerlige forbedringer av SEO-posisjonen din.
