# SEO-arbeitsflyt med Claude

Søkemotoroptimalisering (SEO) innebærer komplekse, repetitive oppgaver som drar nytte av AI-assistanse. Claude Code kan hjelpe deg med å automatisere og akselerere SEO-arbeidsflyten, fra tekniske revisjoner til innholdsoptimisering og dataanalyse.

## Hvorfor Claude for SEO?

Claude Code leser kodebaser, redigerer filer, kjører kommandoer og integreres med utviklingsverktøy—egenskaper som oversetter direkte til SEO-arbeid:

- **Innholdsanalyse**: Analyser og optimaliser raskt store mengder webinnhold for lesbarhet, nøkkelordsplassering og struktur.
- **Tekniske revisjoner**: Automatiser kontroller for vanlige SEO-problemer som manglende metakoder, brutte omdirigeringer og indekseringsproblemer.
- **Databehandling**: Konverter rådata fra Google Search Console eller Analytics til handlingsfulle innsikter.
- **Batchoperasjoner**: Skaler manuelle SEO-oppgaver over hundrevis av sider på minutter.

## Sentrale SEO-oppgaver du kan automatisere

### 1. Optimalisering av metakoder

Claude Code kan revidere og reparere metakoder over hele nettstedet ditt:

```
Analyser alle sider i /src for:
- Manglende eller dupliserte title-koder
- Meta-beskrivelser under 120 eller over 160 tegn
- Manglende H1-koder
- Generere optimaliserte versjoner basert på sideinnhold
```

Gi Claude sideinnholdet ditt, og det vil foreslå title-koder og meta-beskrivelser som inkluderer målnøkkelord samtidig som de respekterer tegngrenser—en kritisk oppgave for store nettsteder.

### 2. Strategi for interne lenker

Identifiser lenkemuligheter ved å la Claude:

- Skanne innholdet ditt for nøkkelordomtaler
- Foreslå relevant ankortekst og målsider
- Flagg isolerte sider uten innkommende lenker
- Generer en lenkekart

### 3. Implementering av skjemamarkering

Legg til strukturerte datamarkering (JSON-LD) på nettstedet ditt:

```
For alle produktsider i /products:
- Trekk ut produktnavn, pris, vurdering, tilgjengelighet
- Generere schema.org/Product JSON-LD
- Injiser i mal eller individuelle filer
```

Dette hjelper søkemotorer med å forstå innholdet ditt og kan forbedre rike utsnitt i søkeresultater.

### 4. Omdirigeringer og kanoniske koder

Når du omstrukturerer nettstedet eller konsoliderer duplisert innhold:

- Revidere eksisterende 301-omdirigeringer
- Identifiser sider som trenger kanoniske koder
- Generere et omdirigerings-kart
- Legg kanoniske koder til maler

### 5. Analyse av innholdsgap

Sammenlign innholdet ditt med konkurrenter eller nøkkelordsister:

```
Gitt en liste med 500 målnøkkelord:
- Sjekk hvilke nøkkelord nettstedet ditt rangeringer for
- Identifiser høyintensjonsnøkkelord du mangler
- Foreslå innholdsemner for å fylle gapet
- Estimer trafikk per emne
```

### 6. Generering av robots.txt og sitemap

Automatiser crawl-optimalisering:

- Generer robots.txt-regler basert på nettstedets struktur
- Opprett XML-sitemap for Google og Bing
- Sikre at alle indekserbare sider er inkludert
- Ekskluder sider med lav verdi (admin, duplisert innhold)

### 7. Analyse av søkeresultater

Behandle data fra Google Search Console:

```
Eksporter Search Console-dataene og be Claude om å:
- Identifisere toppytende spørringer og sider
- Finne spørringer med høye visninger men lav CTR
- Spot rankingtrendre over tid
- Anbefale sider å optimalisere
```

## Praktisk arbeitsflyt-eksempel

### Scenario: Optimalisering av 100 produktsider

1. **Revisjonsfase**: "Analyser vår /products-katalog og rapporter om SEO-helse—title-koder, meta-beskrivelser, H1-koder og manglende skjemamarkering."

2. **Optimaliseringsfase**: "For hver produktside, generer:
   - En unik title-kode (55–60 tegn) som inkluderer produktnavn og hovedfordel
   - En meta-beskrivelse (155–160 tegn) med oppfordring til handling
   - Produkt-skjema JSON-LD med navn, pris, vurdering og tilgjengelighet"

3. **Implementeringsfase**: Claude Code kan deretter anvende disse endringene på alle 100 filer automatisk.

4. **Valideringsfase**: "Sjekk at alle endringer ble brukt riktig, ingen duplikater finnes, og skjemaet er gyldig i henhold til schema.org."

5. **Rapporteringsfase**: "Generer en CSV-oppsummering av gamle vs. nye metakoder og fremhev eventuelle filer som trenger manuell gjennomgang."

## Integrasjon med SEO-verktøy

Claude Code kan forberede data for SEO-stakken din:

- **Google Search Console**: Eksporter data, analyser trender og identifiser optimaliseringsmuligheter.
- **Analytics**: Kombinere trafikdata med på-side-metrikk for å prioritere forbedringer.
- **Rankingsporing**: Parse rankingrapporter og korreler med innholdsendringer.
- **Nøkkelordsverktøy**: Behandle CSV-data for nøkkelordsforskning og align med nettstedets struktur.

## Beste praksis

1. **Start i småskala**: Test Claudes SEO-forslag på noen få sider før bulkoperasjoner.
2. **Bekreft kvalitet**: Gjennomgå alltid generert innhold og metadata—SEO-kvalitet avhenger av det.
3. **Dokumenter endringer**: Bevar en logg over alle endringer for ansvarlighet og rollback om nødvendig.
4. **Overvåk resultater**: Spor metrikk før og etter for å måle virkningen av Claudes optimaliseringer.
5. **Kombiner menneskelig og AI**: Bruk Claude for analyse og automatisering, men hold menneskelige granskere for endelig godkjenning.
6. **Respekter retningslinjer**: Følg Googles SEO Starter Guide (unngå nøkelordsfylling, prioriter brukeropplevelse, sikre mobilvenlig).

## Nøkkelprinsipper for SEO (fra Googles SEO Starter Guide)

- **Høykvalitetsinnhold** er grunnleggende; optimaliser for brukere først, søkemotorer andre.
- **Title- og metakoder** bør være unike, beskrivende og inkludere målnøkkelord naturlig.
- **Mobiloptimalisering** er kritisk—de fleste søk skjer på mobilenheter.
- **Nettstedhastighet** betyr noe; Claude kan hjelpe til med å revidere flaskehalser for ytelse.
- **Strukturerte data** (skjemamarkering) hjelper søkemotorer med å forstå innholdet ditt.
- **Baklenker** og autoritet forblir viktig; Claude kan revidere lenkehelp.

## Kom i gang

1. Forbered nettstedets struktur og innhold i tilgjengelige formater (HTML, Markdown, JSON, CSV).
2. Definer SEO-målene dine (f.eks. forbedre gjennomsnittsrangeringposisjon, øke organisk trafikk).
3. Be Claude om å revidere spesifikke områder (teknisk, innhold, ytelse).
4. Gjennomgå anbefalinger og refiner basert på forretningsprioriteringer.
5. Bruk Claude Code til å implementere endringer i stor skala.
6. Overvåk resultater ved hjelp av analyseplatformen din.
