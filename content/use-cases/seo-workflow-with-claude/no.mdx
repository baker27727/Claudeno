## Oversikt

Claude Code transformerer SEO-arbeidsflyter ved å automatisere gjentakende tekniske oppgaver og gi intelligent analyse. Enten du optimaliserer innhold, gjennomfører revisjoner av nettstedstruktur, eller implementerer strukturert data, kan Claude utføre kode direkte på dine kodefiler og utviklingsmiljø.

## Viktige SEO-oppgaver Claude kan automatisere

### 1. Innholdsanalyse og optimalisering

Claude Code kan:
- **Analysere sidinnhold** for nøkkelordsfrekvens, lesbarhetsmålinger og semantisk relevans
- **Generere titler og metabeskrivelser** som balanserer nøkkelordinkludering med klikk-gjennom-optimalisering
- **Identifisere innholdsgap** ved å sammenligne ditt innhold mot konkurrentesider
- **Kontrollere overskrifthierarki** (H1, H2, H3) for å sikre riktig semantisk struktur
- **Revidere intern lenking** mønstre og foreslå optimiseringsmuligheter

**Eksempel arbeitsflyt:**
```
1. Gi Claude ditt sidinnhold
2. Spesifiser målnøkkelord og søkeintensjon
3. Claude genererer optimaliserte versjoner av tittel, beskrivelse og overskrifter
4. Gjennomgå forslag og implementer endringer
```

### 2. Tekniske SEO-revisjoner

Claude Code er dyktig til å undersøke ditt nettstedets tekniske fundament:
- **Crawle URL-strukturer** og identifisere omdirigeringskjeder eller brutte interne lenker
- **Validere robots.txt og sitemap.xml** filer for fullstendighet og korrekthet
- **Kontrollere canonical tags** implementering og identifisere duplikatinnhold-problemer
- **Revidere svarhoveder** (cache-control, ETag, kompresjon)
- **Teste sidhastighet-målinger** og foreslå optimiseringsmål
- **Kontrollere mobil responsivitet** ved hjelp av viewport meta-tags og CSS

**Vanlige revisjoner:**
- Identifisering av manglende eller duplikerte canonical tags
- Kontroll av at robots.txt-direktiver stemmer overens med indekseringsstrategi
- Validering av sitemap-dekning og friskhet
- Oppdagelse og fikser av HTTP/HTTPS blandede innholdsproblemer

### 3. Implementering av strukturert data

Strukturert data er avgjørende for søkesynlighet og rike resultater. Claude kan:
- **Generere JSON-LD skjemamarkering** for artikler, produkter, FAQ og lokale virksomheter
- **Validere eksisterende skjema** mot Googles krav
- **Implementere brødsmulmarkering** for forbedret navigasjonsvisning
- **Opprette FAQ-skjema** fra dokumentasjonen din
- **Generere produktskjema** med priser, tilgjengelighet og anmeldelser

**Rask start:**
Gi Claude ditt sidinnhold og ønsket rik resultattype (artikkel, produkt, lokal virksomhet), og den genererer produksjonsklar skjema.

### 4. Nøkkelordsanalyse og mapping

Claude kan behandle og organisere SEO-data:
- **Analysere søkevolum og konkurransedata** for å prioritere nøkkelord
- **Kartlegge nøkkelord til eksisterende innhold** og identifisere gap
- **Gruppere relaterte nøkkelord** til emnetilsamlinger
- **Generere innholdsrapporter** med nøkkelordanbefalinger og søkeintensjonanalyse
- **Opprette SEO-vennlige URL-strukturer** tilpasset nøkkelordtargeting

### 5. Rapportgenerering og overvåking

Automatiser din SEO-rapportering:
- **Analysere Google Search Console-data** og generere ledersamendrag
- **Sammenligne ytelsesproblemer** på tvers av datoer
- **Spore nøkkelord-rankingendringer** og identifisere trender
- **Overvåke Core Web Vitals-samsvar** og identifisere sider som trenger optimalisering
- **Generere revisjonsrapporter** som dokumenterer problemer og fikser

## Vanlige SEO-brukstilfeller

### Brukstilfelle 1: Optimaliser 404-feilside
**Oppgave:** Forbedre SEO-verdien av 404-sider gjennom riktige omdirigeringer og intern lenking
- Claude analyserer brutte lenkmønstre fra serverlogger
- Genererer 301 omdirigeringsmapper til relevant innhold
- Foreslår interne lenker for 404-siden selv
- Oppdaterer omdirigeringsfilen din med riktige HTTP-statuskoder

### Brukstilfelle 2: Implementer FAQ-skjema
**Oppgave:** Legg til FAQ-strukturert data for å øke synlighet for utvalgt utdrag
- Gi Claude ditt FAQ-sideinnhold
- Claude genererer riktig JSON-LD FAQ-skjema
- Validerer resultat mot Googles krav
- Implementerer skjema i sidmalen din

### Brukstilfelle 3: Revisjon av nettstedstruktur for e-handel
**Oppgave:** Sikr at produktsider er riktig oppdagbare og optimaliserte
- Claude analyserer URL-hierarki og kategoristuktur
- Validerer canonical tags på alle produktsider
- Kontrollerer brødsmulimplementering
- Genererer produktskjema for hver side
- Rapporterer kategorisider som mangler intern lenking

### Brukstilfelle 4: Innholdsgapanalyse
**Oppgave:** Identifiser emner konkurrenter dekker som du ikke gjør
- Gi konkurrent-URLer og målnøkkelord
- Claude analyserer innholdstemaer og nøkkelordsdekning
- Identifiserer temegap med søkepotensial
- Genererer kort oversikt for nytt innhold

## Beste praksis for SEO med Claude Code

### 1. Gi kontekst
- Del målgruppen og søkeintensjon
- Inkluder konkurrenteksempler (når relevant)
- Spesifiser CMS-plattformen eller rammeverket ditt
- Nevn eksisterende SEO-retningslinjer

### 2. Tenk systemer, ikke enkelttilfeller
- Bruk optimaliseringer på tvers av malssider, ikke bare individuelle URLer
- Bruk Claude til å opprette gjenbrukbare skjemaer
- Generer prosesser som kan skaleres (f.eks. automatiserte rapporter)

### 3. Valider før publisering
- Test generert skjema med Googles Rich Results Test
- Kontroller sidhastighet-metrikker før og etter endringer
- Bruk Search Console til å overvåke crawl-feil etter implementering
- A/B test tittel-/beskrivelsesvarianter når mulig

### 4. Bevar versjonskontroll
- Behold sikkerhetskopier av originale filer før Claude-assistert endringer
- Dokumenter alle modifikasjoner for etterlevelse og revisjoner
- Gjennomgå kodeendringer nøye før produksjonsdistribusjon

### 5. Balanser automatisering med menneskelig skjønn
- Claude genererer datadrevne anbefalinger; du setter SEO-strategi
- Bruk Claude for tungt løft (analyse, skjemakenerering, rapportbygging)
- Behold kreative beslutninger for deg (budskap, tone, unik posisjonering)
- Verifiser at tekniske anbefalinger stemmer overens med plattformfunksjoner

## Feilsøking av vanlige problemer

**Problem: Generert skjema validerer ikke**
- Verifiser at alle nødvendige felt er inkludert per Googles dokumentasjon
- Kontroller JSON-syntaks for riktig escaping av sitater
- Sikr at datoformater samsvarer med ISO 8601-standarden
- Test med Googles Rich Results Test-verktøy

**Problem: Omdirigeringer fungerer ikke riktig**
- Bekreft at HTTP-statuskode er 301 (permanent) ikke 302 (midlertidig)
- Kontroller omdirigeringskjedelen (unngå flere hopp)
- Verifiser at destinasjons-URL returnerer 200-statuskode
- Tøm CDN-hurtigbuffer etter implementering av omdirigeringer

**Problem: Sidhastighet-poeng har ikke forbedret seg**
- Claude kan identifisere optimiseringsmuligheter; faktiske forbedringer avhenger av hosting
- Prioriter fikser etter påvirkning (bilder > JavaScript > CSS)
- Test på Core Web Vitals med sanntidsbrukersovervåking
- Vurder serversidforbedringer (kompresjon, hurtigbuffer)
