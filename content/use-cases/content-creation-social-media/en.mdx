## Overview

Social media managers and content creators can use Claude Code to streamline content production workflows. Claude helps generate captions, optimize posts for different platforms, create hashtag strategies, and manage multi-language content—all with consistent brand voice.

## Quick Start

### 1. Generate Social Media Captions

Create a prompt that generates platform-specific captions:

```
Write a Twitter caption (max 280 characters) for a product launch announcement:

Product: New AI-powered scheduling tool
Tone: Excited, professional
Include: Call to action, relevant emoji
```

Claude will generate multiple options you can refine and publish directly to your platform.

### 2. Optimize Content for Multiple Platforms

Take one piece of core content and adapt it:

```
Original LinkedIn post: [your post]

Adapt this for:
- Twitter (concise, punchy)
- Instagram (visual focus, hashtag strategy)
- TikTok (casual, trending language)
- Email newsletter (professional summary)

Keep the same core message across all versions.
```

### 3. Generate Hashtag Strategies

Let Claude research and suggest hashtags:

```
Analyze hashtag performance for posts about [your topic].
Suggest:
- High-reach hashtags (100k+ posts)
- Niche hashtags (10k-100k posts)
- Branded hashtag variants
- Trending hashtags this week
```

## Practical Applications

### Content Calendar Planning

Use Claude to brainstorm weekly content themes, topics, and posting schedules:

```
Create a 4-week content calendar for a [your industry] business.
Include:
- Daily themes (Monday motivation, Wednesday tips, etc.)
- 3 post ideas per day
- Suggested posting times
- Cross-platform adaptation notes
```

### Bulk Content Generation

Generate multiple variations for A/B testing:

```
Create 5 versions of a social media post promoting [product/service].
Vary:
- Headline approach
- Emotional tone
- Call-to-action style
- Length (short/medium/long)

Format each with platform-specific character counts.
```

### Brand Voice Consistency

Define your brand voice once, then apply it across posts:

```
Brand guidelines:
- Tone: [describe]
- Vocabulary: [list key terms]
- Topics to avoid: [list]
- Call-to-action style: [describe]

Rewrite this post to match the brand voice: [original post]
```

## Advanced Techniques

### Automated Caption + Image Description Workflow

Pair captions with accessible image descriptions:

```
Image: [describe what's in the image]

Generate:
1. Main social media caption (with emoji and hashtags)
2. Alt text for accessibility (concise, descriptive)
3. Engagement-focused comment starter
```

### Performance Analysis & Optimization

Analyze past content and get improvement suggestions:

```
Analyze these posts by engagement:
- [Post 1 with metrics]
- [Post 2 with metrics]
- [Post 3 with metrics]

Identify patterns and suggest improvements for future posts.
```

### Trending Topic Adaptation

Quickly capitalize on trending conversations:

```
Trending topic: [current trend]
Your business: [your business description]

Generate a relevant, timely post that:
- Adds value (don't just follow the trend)
- Matches our brand voice
- Encourages shares/discussion
- Includes 1-2 relevant hashtags
```

## Tips for Best Results

- **Provide context**: Include audience demographics, industry, and brand voice in your prompts
- **Iterate quickly**: Use Claude to generate multiple versions, then select and refine the best ones
- **Test variations**: A/B test headlines, emojis, and CTAs to see what resonates
- **Maintain consistency**: Save your brand guidelines and reference them in every prompt
- **Use templates**: Create reusable prompt templates for weekly posts, announcements, and campaigns
- **Add personality**: Include specific examples of your brand's tone so Claude matches it naturally
