## Overview

Project management involves coordinating people, timelines, and resources—tasks where Claude can add significant value. Claude Code enables you to:

- **Automate planning workflows**: Generate project templates, breakdown structures, and timelines
- **Track and analyze status**: Parse status documents and dashboards, generate insights
- **Identify risks early**: Review scope, schedules, and dependencies for potential issues
- **Process team communication**: Extract action items from meeting notes and emails
- **Generate reports**: Create executive summaries, burndown charts, and progress dashboards

## Getting Started

### 1. Project Planning & Breakdown

Start with project definition. Create a scope document, and have Claude help structure it:

```
User prompt:
"I'm starting a website redesign project. We need to update our homepage, product pages, and checkout flow. 
The timeline is 8 weeks, and we have 3 designers and 2 developers. Create a work breakdown structure (WBS) 
with milestones and a draft timeline."
```

Claude will:
- Create a hierarchical WBS (phases → deliverables → tasks)
- Suggest realistic milestones based on scope and team size
- Identify critical path items
- Flag dependency chains

### 2. Status Tracking & Reporting

Maintain project status in simple text or CSV files. Have Claude parse and analyze:

```
User prompt:
"Here's our current project status [file]. Generate a one-page executive summary highlighting: 
1) tasks completed this week, 2) tasks at risk, 3) blockers, and 4) upcoming critical milestones."
```

Claude will extract key information, identify trends, and flag items needing attention.

### 3. Risk & Issue Management

Provide project documents (scope, schedule, resource plan), and ask Claude to identify risks:

```
User prompt:
"Analyze our project plan for risks. Consider scope creep, resource constraints, and schedule pressure. 
Rank the top 5 risks by impact and likelihood, and suggest mitigation strategies."
```

Claude can identify common patterns (understaffing, unrealistic timelines, unclear requirements) and suggest mitigation approaches.

### 4. Meeting Notes & Action Items

After meetings, have Claude process notes:

```
User prompt:
"Extract from these meeting notes: 1) action items with owners and due dates, 2) decisions made, 
3) open questions, and 4) risks discussed. Format as a structured list."
```

Claude will parse narrative notes and create actionable, tracked items.

## Best Practices

### Be Specific with Context
- Provide the full project scope, not just isolated questions
- Share timeline constraints, team size, and dependencies
- Include past project data if asking for estimates

### Use Templates
- Create reusable prompts for recurring tasks (status reports, risk reviews, action item extraction)
- Save Claude's structured templates for consistency across projects

### Validate Outputs
- Claude's suggestions are starting points, not final answers
- Review risk assessments against your team's actual capacity and constraints
- Cross-check generated timelines with your team's input

### Integrate with Tools
- Export Claude's outputs to your project management tool (Jira, Monday.com, Asana)
- Use Claude Code to read project files and keep summaries updated
- Combine Claude's analysis with your team's domain knowledge

## Common Workflows

### Weekly Status Report Generation
1. Collect status updates from team (in a shared document or file)
2. Ask Claude to read the file and generate a structured report
3. Claude extracts completed work, blockers, and upcoming priorities
4. Review and customize the report before sharing with stakeholders

### Resource Allocation Analysis
1. Provide Claude with task list and team member capacity
2. Ask Claude to identify conflicts (over-allocated team members, idle capacity)
3. Use Claude's suggestions to rebalance the workload

### Post-Project Retrospective
1. Collect project data (original plan vs. actual, blockers, successes)
2. Ask Claude to analyze variance and identify lessons learned
3. Use insights for improving future project planning

## Tips

- **Ask Claude to challenge assumptions**: "What could derail this timeline? What are we underestimating?"
- **Use Claude for scenario planning**: "If we lose one developer, how does the timeline shift?"
- **Leverage Claude for documentation**: Generate project charters, communication plans, and handoff documents
- **Combine with APIs**: Use Claude alongside your project management tool's API for automated, intelligent status updates
