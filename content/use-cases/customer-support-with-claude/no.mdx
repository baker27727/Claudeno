Supportteam besvarer de samme spørsmålene mange ganger om dagen. **Claude Code** hjelper til med å utkaste konsistente, hjelpsomme svar og gjøre vanlige spørsmål om til en gjenbrukbar kunnskapsbase.

Denne guiden viser hvordan supportteam kan bruke Claude Code til svar, FAQ-er, billettanalyse og interne guider.

## Hvorfor supportteam bruker Claude Code

Claude Code erstatter ikke menneskelig empati, men det fjerner repeterende skrivearbeid.

Nøkkelfordeler:

- **Utkast svar raskere** på vanlige spørsmål.
- **Bygg en Markdown-FAQ** fra ekte support-samtaler.
- **Kategoriser billett-eksport** etter tema eller sentiment.
- **Oppsummer lange e-posttråder** for eskalering.
- **Lag interne feilsøkingsguider** for agenter.
- **Hold maler filbaserte** slik at teamet kan gjenbruke og forbedre dem.

## Bruksområde 1: utkast svar fra en kundemelding

Lag `ticket.md`:

```markdown
Kunde: Jeg kan ikke tilbakestille passordet mitt. Lenken sier utløpt selv om jeg nettopp mottok den.
Kontotype: Premium
Tidligere kontakt: Ingen
```

Spør Claude:

```bash
claude "Les ticket.md og utkast et høflig, hjelpsomt support-svar. Bekreft problemet, forklar den sannsynlige årsaken og tilby et klart neste steg."
```

Claude returnerer et svar du kan gjennomgå, personalisere og sende.

## Bruksområde 2: lag en FAQ fra supportbilletter

Eksporter et utvalg billetter som `support-tickets.csv`:

```csv
id,subject,message
101,Passordtilbakestilling fungerer ikke,Lenken sier utløpt...
102,Hvordan endrer jeg planen,Jeg vil oppgradere...
```

Kjør:

```bash
claude "Les support-tickets.csv og lag en Markdown-FAQ med de 10 vanligste spørsmålene og konsise svar. Grupper relaterte spørsmål sammen."
```

FAQ-en blir en selvbetjeningsressurs og en agentreferanse.

## Bruksområde 3: kategoriser billetter etter tema

Forståelse av billett-trender hjelper med å prioritere feilrettinger.

```bash
claude "Les support-tickets.csv og kategoriser hver billett i én av: Fakturering, Konto, Teknisk, Feature Request eller Annet. Returner resultatene som en CSV med de originale kolonnene pluss en 'category'-kolonne."
```

Du kan deretter telle kategorier og rapportere trender til produktteamet.

## Bruksområde 4: oppsummer en lang tråd

Lim inn en lang e-posttråd i `thread.md` og spør:

```bash
claude "Les thread.md og oppsummer: hva er problemet, hva har blitt prøvd, hva er kundens nåværende forespørsel, og hva bør neste handling være?"
```

Dette er uvurderlig ved eskalering av komplekse saker.

## Bruksområde 5: intern feilsøkingsguide

Gjør agentnotater om til en strukturert guide:

```bash
claude "Les agent-notes.md og skriv en intern feilsøkingsguide for problemer med passordtilbakestilling. Inkluder symptomer, årsaker og trinnvis løsning."
```

Nye agenter kan bruke denne til å løse vanlige problemer selvstendig.

## Beste praksis for support med Claude Code

### 1. Lagre godkjente svar som maler
Bygg et bibliotek med `reply-templates/*.md`-filer slik at Claude kan matche din merkestemme.

### 2. Anonymiser data før analyse
Fjern navn, e-poster og kontoider fra billett-eksport.

### 3. Gå alltid gjennom før sending
AI-svar kan høres korrekte ut, men mangle følelsesmessig nyanser eller spesialtilfeller.

### 4. Hold tekniske trinn nøyaktige
Be Claude basere feilsøkingstrinn på din nåværende produktdokumentasjon.

### 5. Mål hva du automatiserer
Spor hvilke svar som kommer fra maler og hvilke som fortsatt trenger menneskelig forfattering.

## Vanlige feil å unngå

- **Sende AI-svar uredigert** — alltid legg til et menneskelig gjennomgangstrinn.
- **Inkludere feil produktdetaljer** — verifiser funksjoner og lenker.
- **Dele for mye kundedata** — følg personvernpolicyen din.
- **Ignorere eskaleringssignaler** — sinte eller komplekse saker trenger et menneske.
