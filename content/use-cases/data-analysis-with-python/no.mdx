# Dataanalyse med Python og Claude Code

## Oversikt

Mens Excel er utmerket for grunnleggende regnearkarbeid, tilbyr Python kraftigere verktøy for dypere dataanalyse. Claude Code bygger en bro ved å hjelpe deg skrive Python-skript som utforsker data, beregner statistikk, identifiserer mønstre og genererer handlingskraftig innsikt—uten å trenge å være programmeringekspert.

## Hvorfor Python for dataanalyse?

**Begrensninger i Excel:**
- Formelkompleksitet vokser raskt
- Ytelse forverres med store datasett (100k+ rader)
- Vanskelig å spore transformasjonstrinn
- Begrenset statistisk og visualiseringsfunksjoner

**Fordeler med Python og pandas:**
- Håndter millioner av rader effektivt
- Skriv lesbar, gjentakelig analyskode
- Få tilgang til avanserte statistiske metoder
- Lag visualiseringer av publiseringskvalitet
- Integrer med andre verktøy og datakilder

## Vanlige analysarbeidsflyten

### 1. Utforskende dataanalyse (EDA)

Når du mottar et nytt datasett, start med spørsmål:

- Hva er dimensjonene og strukturen?
- Hvilke kolonner har vi, og hva er typene deres?
- Hvor mye manglende data finnes det?
- Hva er distribusjonene av nøkkelvariablene?
- Er det åpenbare uteliggere eller anomalier?

**Claude Code hjelper ved å:**
- Skrive kode for å profilere dataene
- Generere sammendragsstatistikk
- Lage visualiseringer av distribusjoner
- Identifisere datakvalitetsproblemer

**Eksempel:**
```python
import pandas as pd

# Last og utforsk
df = pd.read_csv('sales_data.csv')
print(df.info())  # Datatyper og manglende verdier
print(df.describe())  # Sammendragsstatistikk
print(df.isnull().sum())  # Antall manglende verdier
```

### 2. Datarensing og forberedelse

Rå data er sjelden ren. Vanlige oppgaver inkluderer:

- **Håndtering av manglende verdier** (fjern, fylt inn eller flagg)
- **Fjerning av duplikater**
- **Standardisering av formater** (datoer, telefonnumre, adresser)
- **Oppdagelse og behandling av uteliggere**
- **Typekonvertering** (strenger til datoer osv.)

Claude Code kan automatisere disse repetitive trinnene med robust feilhåndtering.

### 3. Statistisk analyse

Svar på kvantitative forretningsspørsmål:

- Hva er den gjennomsnittlige kundens levetidsverdi etter region?
- Hvordan korrelerer produktsalg med markedsføringsutgifter?
- Er det en signifikant forskjell i ytelse mellom to grupper?
- Hva er trendene over tid?

**pandas og scipy sammen gir:**
- Korrelasjon og regresjonsanalyse
- Hypotesetesting
- Tidsserieanalyse
- Aggregering og gruppering

### 4. Visualisering og rapportering

Omgjøring av data til handlingskraftig innsikt krever klar kommunikasjon:

- **Matplotlib/Seaborn**: Statistiske grafikk
- **Plotly**: Interaktive, webklare visualiseringer
- **Pandas-plotting**: Rask eksplorativ plotting

Claude Code kan generere diagrammer, lage dashbord eller eksportere formaterte rapporter.

## Vanlige analysemønstre

### Gruppering og aggregering
```python
# Salg etter region og måned
sales_summary = df.groupby(['region', 'month']).agg({
    'revenue': 'sum',
    'units': 'sum',
    'orders': 'count'
})
```

### Håndtering av manglende data
```python
# Fyll manglende verdier med kolonnemiddelverdi
df['price'].fillna(df['price'].mean(), inplace=True)

# Eller fjern rader med manglende verdier
df.dropna(inplace=True)
```

### Oppretting av nye kolonner
```python
# Beregn avledede metrikker
df['profit_margin'] = (df['revenue'] - df['cost']) / df['revenue']
df['customer_segment'] = pd.cut(df['spend'], bins=3, labels=['Low', 'Medium', 'High'])
```

## Tips for effektiv analyse

1. **Start enkelt**: Forstå dataene før du bygger komplekse modeller
2. **Dokumentér forutsetninger**: Noter hva du antar om dataene
3. **Valider resultater**: Sjekk at utdataene gir mening (sammenlign med Excel hvis nødvendig)
4. **Automatiser, ikke over-ingeniør**: Løs problemet for hånden, deretter generalisere
5. **Del koden din**: Kommentarer og docstrings hjelper andre å forstå arbeidet ditt

## Fra analyse til handling

Dataanalyse alene er ikke verdifull—den må drive beslutninger:

- **Dashbordopprettelse**: Visualiser nøkkelmålinger for løpende overvåking
- **Automatisk rapportering**: Planlegg analysen til å kjøre ukentlig eller månedlig
- **Prediktive modeller**: Bruk tidligere data til å forutsi fremtidiske resultater
- **Prosesskvalitet**: Bruk innsikt til å optimalisere operasjoner

## Neste skritt

Start med et datasett du kjenner godt (ditt eget salg, inventar eller kundedata). Still et spesifikt, svarbart spørsmål og arbeide med Claude Code for å utforske det. Når du blir komfortabel med arbeidsflyten, takler du mer komplekse analyser.
