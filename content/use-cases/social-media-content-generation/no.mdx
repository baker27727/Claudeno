## Oversikt

Sosiale medieteam står under konstant press for å produsere frisk, merkevareavstemt innhold på flere plattformer. Claude Code lar deg automatisere opprettelsen, variasjonen og optimaliseringen av sosiale poster mens du opprettholder merkestemmen din.

Denne guiden viser hvordan du bruker Claude Code til å:

- Generere flere postavariasjoner for et enkelt emne
- Lage plattformspesifikt innhold (Twitter, LinkedIn, Instagram, TikTok)
- Batch-prosessere innholdskalendere
- Optimalisere poster for engagement og nåbarhet
- Opprettholde merkekonsistens på tvers av kanaler

## Hvorfor bruke Claude Code for sosiale medieinnhold?

**Hastighet**: Generer dusinvis av postavariasjoner på minutter i stedet for timer med manuell skriving.

**Konsistens**: Claude opprettholder merkeveiledningene dine og meldinger på tvers av alle poster.

**Automatisering**: Batch-prosess hele innholdskalendere eller kampanjebriefs automatisk.

**Variasjon**: Test raskt forskjellige vinkler, toner og hooks for samme emne.

**Skalabilitet**: Fungerer for små kontoer og storskala sosiale medieteam.

## Opprett merkeveiledninger

Lagre merkeveiledningene dine i `.claude/brand-guidelines.md` slik at Claude Code refererer til dem automatisk:

```markdown
# Merkeveiledninger

## Tone
- Vennlig og tilgjengelig, men profesjonell
- Unngå bedriftsjargon
- Bruk samtalespråk

## Nøkkelmeldinger
- Vi gir skapere muligheten til å bygge fantastiske ting
- Fokuser på innvirkning, ikke funksjoner
- Vis virkelige kundestory

## Hashtag-strategi
- Primær: #CreatorTools #BuildTogether
- Sekundær: #NoCode #Automation
- Unngå: altfor trendy, ikke-relaterte hashtags

## Innholdssøyler
1. Pedagogiske tips (40%)
2. Produktoppdateringer (30%)
3. Kundeprofilering (20%)
4. Industri-innsikter (10%)
```

## Generer enkeltposter

Bruk Claude Code til å lage en post fra en enkel idé:

**Prompt til Claude Code:**
> Skriv en Twitter-post om den nyeste funksjonen vår. Hold det under 280 tegn, inkluder en call-to-action, og referer til merkeveiledningene våre.

Claude Code vil:
1. Lese merkeveiledningene dine
2. Generere en engasjerende, merkevareavstemt post
3. Sikre at den passer til plattformens begrensninger

**Eksempel på output:**
```
Twitter (280 tegn):
"Akkurat lansert vår beste funksjon ennå 🚀 AI-drevet posteoptimalisering som lærer DIN publikum. Prøv gratis → [link] #CreatorTools"

LinkedIn (lengre, profesjonell):
"I dag er vi begeistret for å kunngjøre en stor milepæl: vår nye AI-optimaliseringsmotor er nå live.

Vi har brukt måneder på å jobbe med skapere for å forstå hva de trenger mest. Resultatet? Smartere innsikter, bedre engagement og mer tid til å fokusere på det som betyr noe.

Se hvordan kundene våre allerede ser 40 % høyere engagement → [link]"
```

## Batch-generer innholdskalender

Lag et Python-skript for å generere en ukes verdt av poster:

**`batch-content.py`**
```python
import json
from datetime import datetime, timedelta

# Emner for uken
topics = [
    {"date": "Monday", "pillar": "Educational", "topic": "Time-saving workflows"},
    {"date": "Tuesday", "pillar": "Product", "topic": "New AI features"},
    {"date": "Wednesday", "pillar": "Customer", "topic": "User success story"},
    {"date": "Thursday", "pillar": "Educational", "topic": "Social strategy tips"},
    {"date": "Friday", "pillar": "Insight", "topic": "Creator trends"},
]

posts = []

for item in topics:
    post_data = {
        "date": item["date"],
        "pillar": item["pillar"],
        "topic": item["topic"],
        "platforms": {
            "twitter": "[Generated by Claude Code]",
            "linkedin": "[Generated by Claude Code]",
            "instagram": "[Generated by Claude Code]",
        },
        "hashtags": "#CreatorTools #BuildTogether",
    }
    posts.append(post_data)

with open("outputs/weekly_calendar.json", "w") as f:
    json.dump(posts, f, indent=2)

print(f"Generated {len(posts)} posts for the week!")
```

**Bruk Claude Code til å fylle inn det genererte innholdet:**
> Les filen `batch-content.py`. For hver emne i `topics`-listen, generer autentiske, merkevareavstemt sosiale poster for Twitter, LinkedIn og Instagram. Lagre alle resultater i `outputs/weekly_calendar.json`.

## Generer flere vinkler for A/B-testing

Test hvilken meldinger som resonerer best med publikummet ditt:

**Prompt:**
> For emnet "Our new API just launched," generer 4 forskjellige Twitter-poster:
> 1. Teknisk vinkel (for utviklere)
> 2. Forretningsfordel-vinkel (for produktledere)
> 3. Kundesuksess-vinkel (sosial bevis)
> 4. Lekefull/uformell vinkel (for yngre publikum)
>
> Hver skal være under 280 tegn og merkevareavstemt.

**Output:**
```

Forretning: "Cut API integration time from weeks to days. 50+ enterprises now ship 10x faster with our platform. [link]"

Lekefull: "we just made it so easy to integrate our API, even your grandma could do it (jk don't let her try) 😄 [link]"
```

## Best Practices

1. **Gjennomfør alltid før posting** – Claude genererer gode grunnlag; din menneskedom sikrer kvalitet og merketilpasning.

2. **A/B test vinkler** – Generer 3–4 varianter av hver post og la publikummet ditt fortelle deg hva som resonerer.

3. **Oppdater merkeveiledninger regelmessig** – Når stemmen din utvikler seg, oppdater `.claude/brand-guidelines.md` for å reflektere gjeldende meldinger.

4. **Bruk plattformsbegrensninger** – La Claude Code tilpasse innhold til Twitters 280 tegn, LinkedIns lengre format eller Instagrams bildetekststil.

5. **Bygg et gjenbrukbart malbibliotek** – Lagre vellykkede prompts i `.claude/instructions.md` for gjentakende innholdstyper.

6. **Spor hva som fungerer** – Logg hvilke poster som presterer best og fôr det læring tilbake til merkeveiledningene dine.

## Vanlige arbeidsflyter

### Ukentlig innholdskalender
- Mandag: Skissere emner for uken
- Tirsdag: Generer alle postavariasjoner
- Onsdag: Gjennomfør, rediger og velg vinnere
- Torsdag: Planlegg poster via plattformen din
- Fredag: Analyser ytelse

### Kampanje Blitz
- Lage kampanjebrevet (emne, publikum, mål)
- Generer 20+ postavariasjoner på minutter
- Velg topp 10
- Planlegg på alle plattformer

### Sanntidsrespons
- Trendende emne dukker opp
- Claude Code genererer merkevareavstemt syn på sekunder
- Gjennomfør og post hvis det passer strategien din

## Begrensninger og når du skal legge til menneskelig berøring

Claude Code utmerker seg ved å generere volum og opprettholde konsistens, men noe innhold gagnes av menneskelig kreativitet:

- **Brudd nyhet eller kriser**: Alltid håndskrive sensitiv meldinger
- **Svært personlige historier**: Autentiske kundesportretteringer fungerer best når skrevet av kunden
- **Langform tankeledelse**: Claude er flott for et første utkast, men CEO-poster bør være personlig raffinert
- **Samfunnshåndtering**: Virkelige samtaler krever virkelige mennesker

## Neste steg

1. Sett opp prosjektstrukturen din med merkeveiledninger

3. Gå til batch-innholdskalendere når du finner rytmen din
4. Mål hva som fungerer og oppdater veiledninger deretter
5. Skaler på flere plattformer etter hvert som du ser resultater

**Pro tips**: Den beste strategien for sosiale medier kombinerer AI-drevet effektivitet med menneskelig innsikt. Bruk Claude Code til å håndtere volumet, og invester tiden din i strategi, samfunn og innholdet som virkelig beveger virksomheten din fremover.
