## Overview

Social media teams face constant pressure to produce fresh, on-brand content across multiple platforms. Claude Code lets you automate the creation, variation, and optimization of social posts while maintaining your brand voice.

This guide shows how to use Claude Code to:

- Generate multiple post variations for a single topic
- Create platform-specific content (Twitter, LinkedIn, Instagram, TikTok)
- Batch-process content calendars
- Optimize posts for engagement and reach
- Maintain brand consistency across channels

## Why Use Claude Code for Social Media Content?

**Speed**: Generate dozens of post variations in minutes instead of hours of manual writing.

**Consistency**: Claude maintains your brand guidelines and messaging across all posts.

**Automation**: Batch-process entire content calendars or campaign briefs automatically.

**Variation**: Quickly test different angles, tones, and hooks for the same topic.

**Scalability**: Works for small accounts and enterprise social media teams alike.

## Create Brand Guidelines

Store your brand guidelines in `.claude/brand-guidelines.md` so Claude Code references them automatically:

```markdown
# Brand Guidelines

## Tone
- Friendly and approachable, but professional
- Avoid corporate jargon
- Use conversational language

## Key Messages
- We empower creators to build amazing things
- Focus on impact, not features
- Show real customer success stories

## Hashtag Strategy
- Primary: #CreatorTools #BuildTogether
- Secondary: #NoCode #Automation
- Avoid: overly trendy, unrelated tags

## Content Pillars
1. Educational tips (40%)
2. Product updates (30%)
3. Customer spotlights (20%)
4. Industry insights (10%)
```

## Batch-Generate Content Calendar

Create a Python script to generate a week's worth of posts:

**`batch-content.py`**
```python
import json
from datetime import datetime, timedelta

# Topics for the week
topics = [
    {"date": "Monday", "pillar": "Educational", "topic": "Time-saving workflows"},
    {"date": "Tuesday", "pillar": "Product", "topic": "New AI features"},
    {"date": "Wednesday", "pillar": "Customer", "topic": "User success story"},
    {"date": "Thursday", "pillar": "Educational", "topic": "Social strategy tips"},
    {"date": "Friday", "pillar": "Insight", "topic": "Creator trends"},
]

posts = []

for item in topics:
    post_data = {
        "date": item["date"],
        "pillar": item["pillar"],
        "topic": item["topic"],
        "platforms": {
            "twitter": "[Generated by Claude Code]",
            "linkedin": "[Generated by Claude Code]",
            "instagram": "[Generated by Claude Code]",
        },
        "hashtags": "#CreatorTools #BuildTogether",
    }
    posts.append(post_data)

with open("outputs/weekly_calendar.json", "w") as f:
    json.dump(posts, f, indent=2)

print(f"Generated {len(posts)} posts for the week!")
```

**Use Claude Code to fill in the generated content:**
> Read the file `batch-content.py`. For each topic in the `topics` list, generate authentic, on-brand social posts for Twitter, LinkedIn, and Instagram. Store all outputs in `outputs/weekly_calendar.json`.

## Best Practices

1. **Always review before posting** – Claude generates great foundations; your human judgment ensures quality and brand fit.

2. **A/B test angles** – Generate 3–4 variants of each post and let your audience tell you what resonates.

3. **Update brand guidelines regularly** – As your voice evolves, update `.claude/brand-guidelines.md` to reflect current messaging.

4. **Use platform constraints** – Have Claude Code tailor content to Twitter's 280 characters, LinkedIn's longer format, or Instagram's caption style.

5. **Build a reusable template library** – Save successful prompts in your `.claude/instructions.md` for recurring content types.

6. **Track what works** – Log which posts perform best and feed that learning back into your brand guidelines.

## Limitations and When to Add Human Touch

Claude Code excels at generating volume and maintaining consistency, but some content benefits from human creativity:

- **Breaking news or crises**: Always hand-craft sensitive messaging
- **Highly personal stories**: Authentic customer spotlights work best when written by the customer
- **Long-form thought leadership**: Claude is great for a first draft, but CEO posts should be personally refined
- **Community management**: Real conversations require real people
