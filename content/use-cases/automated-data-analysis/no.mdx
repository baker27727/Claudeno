## Oversikt

Claude Code kan automatisere gjentakende dataanalyseoppgaver, fra lasting og rensing av datasett til generering av statistiske sammenfatninger og profesjonelle rapporter. Dette er spesielt verdifullt for analytikere og rapporteringsteam som behandler lignende data regelmessig.

## Vanlige brukstilfeller

**Automatiserte rapporteringspipelines**: Generer ukentlige eller månedlige rapporter ved å analysere nye data og automatisk lage sammenfatninger, tabeller og diagrammer.

**Statistisk utforsking**: Be Claude Code om å utforske et datasett, identifisere mønstre, beregne nøkkelmålinger og foreslå videre analyseretninger.

**Datakvalitetskontroller**: Automatiser valideringsskript som sjekker for manglende verdier, uteliggere, inkonsekvenser og genererer datakvalitetsrapporter.

**Visualiseringsgenerering**: Lag flere diagramtyper fra rådata for å støtte ulike interessentkrav—dashboards, trendanalyser eller komparative visualiseringer.

## Kom i gang

### 1. Forbered dataene dine

Start med en CSV-, Excel-fil eller databasetilkobling. Gi Claude Code:
- Eksempeldata eller filsti
- Forventet datastruktur (kolonner, typer)
- Analysemål ("oppsummere salg etter region" eller "identifisere trender i månedlige målinger")

### 2. Be Claude Code om å analysere

Eksempelprompt:
```
Jeg har kvartalsvis salgsdata i sales_data.csv. Kan du:
1. Laste og utforske datasettet
2. Beregne totalt salg etter region
3. Identifisere de 5 beste produktene etter inntekt
4. Lage en visualisering som viser regionale trender
```

Claude Code vil:
- Lese dataene dine med pandas
- Utføre statistiske beregninger med SciPy eller pandas-funksjoner
- Generere diagrammer med matplotlib eller lignende biblioteker
- Vise resultater eller eksportere til filer

### 3. Gjenta og forbedre

Still oppfølgingsspørsmål:
- "Filtrer dette til kun Q4-data"
- "Legg til et konfidensintervall til trendlinjen"
- "Eksporter sammenfattningstabellen som en formatert HTML-rapport"

## Praktiske eksempler

### Ukentlig resultatrapport

Anmodning: "Lag et ukentlig rapportskript som laster metrikdataene våre, beregner år-over-år-vekst, segmenterer etter kundetype og eksporterer en HTML-fil."

Claude Code vil:
1. Skrive pandas-kode for å laste og filtrere nylige data
2. Beregne vekstprosenter og statistisk signifikans
3. Lage en formatert HTML-tabell med betinget formatering
4. Generere støttende visualiseringer

### Datakvalitetsdashboard

Anmodning: "Analyser kunstedatabasen vår for datakvalitet. Sjekk for manglende e-poster, dupliserte ID-er, ugyldige telefonnumre og generer en rapport."

Claude Code vil:
1. Laste databasen med pandas
2. Anvende valideringsregler
3. Oppsummere problemer etter kategori
4. Lage visualiseringer av datakomplettering

### Statistisk hypotesetesting

Anmodning: "Test om konverteringsrater er signifikant forskjellige mellom behandlings- og kontrollgrupper. Jeg har dataene i treatment_data.csv og control_data.csv."

Claude Code vil:
1. Laste begge datasett
2. Bruke SciPy statistiske tester (t-test, chi-square, etc.)
3. Beregne p-verdier og effektstørrelser
4. Presentere resultater med tolking

## Tips for suksess

**Vær spesifikk om utdataformat**: Spesifiser om du vil ha CSV-eksporter, HTML-rapporter eller interaktive visualiseringer.

**Gi eksempeldata**: Deling av noen få rader med data hjelper Claude Code å forstå strukturen og generere mer nøyaktig kode.

**Bruk maler**: Når Claude Code har opprettet et vellykket analyseskrip, kan du gjenbruke og tilpasse det for lignende datasett.

**Kombiner med planlegging**: Eksporter Python-skript som Claude Code opprettere, og planlegg dem deretter med cron-jobber eller oppgaveplanlægger for fullt automatiserte pipelines.

**Versjonskontroll**: Lagre analysesskript i Git slik at du kan spore endringer og samarbeide med kolleger.

## Biblioteker og verktøy

- **pandas**: Datasting, manipulasjon, gruppering og sammendragsstatistikk
- **SciPy**: Statistiske tester, fordelinger og avansert analyse
- **NumPy**: Numerisk beregning og matriseoperasjoner
- **matplotlib/seaborn**: Oppretting av publikasjonsklar visualisering
- **openpyxl/xlsxwriter**: Skriving av formaterte Excel-rapporter

## Neste steg

Start med en enkel analyseoppgave og øk gradvis kompleksiteten. Når du ser hvordan Claude Code tilnærmer seg problemer, vil du utvikle bedre intuisjon for hva som kan automatiseres og hvordan du kan veilede det effektivt.
