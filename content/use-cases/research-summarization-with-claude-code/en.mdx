## Overview

Research projects often involve gathering information from multiple sources, analyzing documents, and synthesizing findings into coherent summaries. Claude Code streamlines these workflows by automating document processing, information extraction, and summary generation.

## Common Research Workflows

### 1. Automated Document Analysis

Use Claude Code to:
- Read multiple research papers or articles
- Extract key findings, methodologies, and conclusions
- Identify common themes across sources
- Create structured summaries with citations

**Example:**
```bash
cd ~/research-project
cc --instructions "Read the PDF files in ./sources, extract key findings about neural networks, and create a markdown summary with citations."
```

### 2. Comparative Research Summaries

Generate side-by-side comparisons:
- Compare methodologies across different studies
- Identify consensus and divergent perspectives
- Create comparison tables or matrices
- Track evolution of ideas over time

### 3. Information Extraction and Organization

Structure research data:
- Extract specific data points (authors, dates, findings, methods)
- Create searchable indexes of research materials
- Generate metadata for document collections
- Build knowledge databases in structured formats (JSON, CSV)

## Getting Started

### Step 1: Organize Your Sources

Create a clear folder structure for your research:
```
research-project/
├── sources/          # Original documents
├── summaries/        # Generated summaries
└── analysis/         # Extracted data and insights
```

### Step 2: Use Claude Code for Processing

Start with a simple instruction:
```bash
cc --instructions "Read all .txt files in ./sources and create a comprehensive summary that identifies the main themes, key findings, and important gaps in the research."
```

Claude Code will:
- Read your documents
- Analyze their content
- Generate structured summaries
- Save results to your project

### Step 3: Refine and Iterate

Use follow-up instructions to:
- Add citations or references
- Reorganize findings by topic
- Extract specific data points
- Compare findings across sources

## Best Practices

### Clear Instructions
Provide specific guidance about:
- What information to extract
- How to structure output
- What format to use (markdown, JSON, tables)
- Any special considerations (keep academic tone, include citations)

### Source Attribution
Always request that Claude Code:
- Track which source each finding comes from
- Include page numbers or section references when possible
- Maintain clear citations in output
- Distinguish between direct quotes and paraphrasing

### Iterative Refinement
Start broad, then narrow down:
1. First pass: Get overview summaries of all sources
2. Second pass: Focus on specific topics of interest
3. Third pass: Extract precise data and create comparisons
4. Final pass: Polish formatting and add context

### Document Management
Keep your research organized:
- Use consistent file naming conventions
- Separate raw sources from processed outputs
- Maintain a research log or index
- Back up important findings regularly

## Example Use Cases

### Literature Review
"Analyze these 10 research papers on machine learning. Create a summary that covers: (1) common methodologies, (2) key findings, (3) gaps in current research, and (4) future directions. Format as a markdown document with proper citations."

### Competitive Analysis
"Review these company reports and articles about our competitors. Extract and compare: pricing strategies, product features, market positioning, and recent announcements. Create a comparison table."

### Policy Research
"Read these government documents and policy papers. Summarize the current regulations, identify key changes from previous versions, and highlight implications for the industry."

### Technical Documentation
"Extract all API endpoints, parameters, and response formats from these API documentation files. Create a structured JSON file and a markdown quick reference guide."

## Advanced Techniques

### Batch Processing
For large document collections, process in batches:
```bash
cc --instructions "Read files 1-5 in ./sources, summarize each, and save results to ./summaries/batch-1/"
```

### Cross-Document Analysis
Identify connections across multiple sources:
```bash
cc --instructions "Analyze all documents and create a network map showing which authors cite each other, which studies build on previous work, and which findings are corroborated by multiple sources."
```

### Automated Taxonomy Creation
Generate organizing structures:
```bash
cc --instructions "Read all research documents and create a hierarchical taxonomy of topics covered. Assign each document to relevant categories and create an index."
```

## Tips for Effective Research

1. **Start with clear questions**: Know what you're looking for before asking Claude Code to summarize.
2. **Use consistent formats**: Request structured output (JSON, tables, markdown lists) for easier analysis.
3. **Verify critical facts**: For important findings, spot-check Claude Code's summaries against source material.
4. **Build incrementally**: Start with a few documents to refine your instructions before processing large batches.
5. **Keep metadata**: Track source information, dates, and versions alongside your summaries.

## Common Challenges and Solutions

**Challenge**: Output is too long or contains unnecessary details.
**Solution**: Specify exactly what information you need and what format to use.

**Challenge**: Missing citations or attribution to sources.
**Solution**: Explicitly request citations and specify the format (author-date, footnotes, etc.).

**Challenge**: Inconsistent summaries across documents.
**Solution**: Provide a template or example of the desired summary format.

**Challenge**: Difficulty with specialized terminology.
**Solution**: Define key terms in your instructions or provide a glossary.
