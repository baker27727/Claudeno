Data analysis often starts with messy files, vague questions, and a lot of trial and error. **Claude Code** helps analysts and operators clean data, write formulas, and generate reusable scripts without leaving the terminal.

This guide covers practical data workflows: CSV cleaning, Excel formulas, Python analysis, and automation.

## Why use Claude Code for data work

Claude Code is file-aware. That means it can read your data files, understand their structure, and produce code or transformed files you can run again later.

Benefits for data work:

- **Clean data faster** by describing transformations in plain language.
- **Write Excel formulas** from descriptions instead of memorising syntax.
- **Generate Python scripts** for analysis, charts, and reports.
- **Document your workflow** because every command and output lives in your project folder.
- **Iterate quickly** without switching between spreadsheet apps and code editors.

## Use case 1: clean a CSV file

You have `sales.csv` with inconsistent casing, blank rows, and extra whitespace. Instead of cleaning it manually, ask Claude Code.

First, inspect the file:

```bash
head sales.csv
```

Then run:

```bash
claude "Read sales.csv, normalise the 'product' column to title case, trim whitespace from all text columns, remove blank rows, and save the result as sales-clean.csv."
```

Claude reads the file, applies the transformations, and writes the cleaned version. You can then verify:

```bash
head sales-clean.csv
```

## Use case 2: summarise a dataset

After cleaning, ask for summary statistics:

```bash
claude "Read sales-clean.csv and report: total revenue, average order value, top 5 products by quantity, and any obvious outliers."
```

Claude returns a readable summary. For deeper analysis, ask it to generate a Python script.

## Use case 3: write Excel formulas

If you prefer spreadsheets, describe what you need and let Claude write the formula:

```bash
claude "Write an Excel formula that returns 'Yes' if B2 is greater than 100 and C2 contains 'completed', otherwise 'No'."
```

Output:

```excel
=IF(AND(B2>100, C2="completed"), "Yes", "No")
```

For more complex logic:

```bash
claude "Write an Excel formula that calculates a 10% discount if quantity is 10 or more, 5% if 5-9, otherwise 0."
```

## Use case 4: generate a Python analysis script

For reusable analysis, ask Claude to write a script:

```bash
claude "Write a Python script that reads sales-clean.csv, calculates total revenue and average order value by product, and prints a sorted table. Save it as analyse_sales.py."
```

Run it:

```bash
python analyse_sales.py
```

If the output needs formatting, iterate:

```bash
claude "Update analyse_sales.py to also save the results to sales-summary.csv."
```

## Use case 5: create a simple chart

Ask Claude to generate a plotting script:

```bash
claude "Write a Python script that reads sales-clean.csv and creates a bar chart of total revenue by product. Save it as chart_revenue.py."
```

Run it:

```bash
python chart_revenue.py
```

You now have a script you can rerun whenever the data updates.

## Use case 6: combine multiple CSV files

If you have monthly reports in separate files:

```bash
claude "Combine all CSV files matching sales-2026-*.csv into one file called sales-2026-combined.csv. Add a 'month' column based on the filename."
```

This saves manual copy-paste work and reduces errors.

## Best practices for data analysis with Claude Code

### 1. Start with a small sample
Test your transformations on a few rows before applying them to the full dataset.

### 2. Keep raw data untouched
Always write transformations to new files. Never overwrite your original data.

### 3. Ask Claude to explain the code
Before running a generated script, ask for a brief explanation of what it does.

### 4. Save reusable scripts
If you expect to repeat the analysis, save the script instead of just reading the output.

### 5. Check data types
Dates, numbers stored as text, and mixed formats are common sources of errors. Ask Claude to validate types.

## Common mistakes to avoid

- **Overwriting source files** — always preserve the original.
- **Trusting summaries blindly** — spot-check numbers against the raw data.
- **Ignoring data types** — a column that looks numeric might be stored as text.
- **Generating scripts you do not understand** — ask for explanations until the logic is clear.
