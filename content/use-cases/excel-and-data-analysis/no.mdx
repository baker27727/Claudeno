Dataanalyse starter ofte med rotete filer, vage spørsmål og mye prøving og feiling. **Claude Code** hjelper analytikere og operatører med å rense data, skrive formler og generere gjenbrukbare skript uten å forlate terminalen.

Denne guiden dekker praktiske dataarbeidsflyter: CSV-rensing, Excel-formler, Python-analyse og automasjon.

## Hvorfor bruke Claude Code til dataarbeid

Claude Code er filbevisst. Det betyr at det kan lese datafilene dine, forstå strukturen deres og produsere kode eller transformerte filer du kan kjøre igjen senere.

Fordeler for dataarbeid:

- **Rens data raskere** ved å beskrive transformasjoner på vanlig språk.
- **Skriv Excel-formler** fra beskrivelser i stedet for å memorere syntaks.
- **Generer Python-skript** for analyse, diagrammer og rapporter.
- **Dokumenter arbeidsflyten din** fordi hver kommando og output lever i prosjektmappen.
- **Iterer raskt** uten å bytte mellom regneark og kodeeditorer.

## Bruksområde 1: rens en CSV-fil

Du har `sales.csv` med inkonsekvent casing, blanke rader og ekstra mellomrom. I stedet for å rense manuelt, spør Claude Code.

Inspekter filen først:

```bash
head sales.csv
```

Kjør deretter:

```bash
claude "Les sales.csv, normaliser 'product'-kolonnen til title case, trim whitespace fra alle tekstkolonner, fjern blanke rader og lagre resultatet som sales-clean.csv."
```

Claude leser filen, utfører transformasjonene og skriver den rensede versjonen. Du kan deretter verifisere:

```bash
head sales-clean.csv
```

## Bruksområde 2: oppsummer et datasett

Etter rensing, be om oppsummerende statistikk:

```bash
claude "Les sales-clean.csv og rapporter: total omsetning, gjennomsnittlig ordreverdi, topp 5 produkter etter kvantum og eventuelle åpenbare avvik."
```

Claude returnerer en lesbar oppsummering. For dypere analyse, be det generere et Python-skript.

## Bruksområde 3: skriv Excel-formler

Hvis du foretrekker regneark, beskriv hva du trenger og la Claude skrive formelen:

```bash
claude "Skriv en Excel-formel som returnerer 'Ja' hvis B2 er større enn 100 og C2 inneholder 'fullført', ellers 'Nei'."
```

Output:

```excel
=HVIS(OG(B2>100; C2="fullført"); "Ja"; "Nei")
```

For mer kompleks logikk:

```bash
claude "Skriv en Excel-formel som beregner 10% rabatt hvis kvantitet er 10 eller mer, 5% hvis 5-9, ellers 0."
```

## Bruksområde 4: generer et Python-analysescript

For gjenbrukbar analyse, be Claude om å skrive et skript:

```bash
claude "Skriv et Python-skript som leser sales-clean.csv, beregner total omsetning og gjennomsnittlig ordreverdi per produkt, og skriver ut en sortert tabell. Lagre det som analyse_sales.py."
```

Kjør det:

```bash
python analyse_sales.py
```

Hvis output trenger formatering, iterer:

```bash
claude "Oppdater analyse_sales.py til også å lagre resultatene i sales-summary.csv."
```

## Bruksområde 5: lag et enkelt diagram

Be Claude generere et plotte-script:

```bash
claude "Skriv et Python-skript som leser sales-clean.csv og lager et stolpediagram av total omsetning per produkt. Lagre det som chart_revenue.py."
```

Kjør det:

```bash
python chart_revenue.py
```

Du har nå et skript du kan kjøre på nytt når dataene oppdateres.

## Bruksområde 6: kombiner flere CSV-filer

Hvis du har månedsrapporter i separate filer:

```bash
claude "Kombiner alle CSV-filer som matcher sales-2026-*.csv til én fil kalt sales-2026-combined.csv. Legg til en 'month'-kolonne basert på filnavnet."
```

Dette sparer manuell kopiering og reduserer feil.

## Beste praksis for dataanalyse med Claude Code

### 1. Start med en liten prøve
Test transformasjonene dine på noen få rader før du bruker dem på hele datasettet.

### 2. Hold rådata urørt
Skriv alltid transformasjoner til nye filer. Overskriv aldri originaldataene.

### 3. Be Claude forklare koden
Før du kjører et generert skript, be om en kort forklaring av hva det gjør.

### 4. Lagre gjenbrukbare skript
Hvis du forventer å gjenta analysen, lagre skriptet i stedet for å bare lese output.

### 5. Sjekk datatyper
Datoer, tall lagret som tekst, og blandede formater er vanlige feilkilder. Be Claude validere typer.

## Vanlige feil å unngå

- **Overskrive kildefiler** — behold alltid originalen.
- **Stole blindt på oppsummeringer** — spot-sjekk tall mot rådata.
- **Ignorere datatyper** — en kolonne som ser numerisk ut, kan være lagret som tekst.
- **Generere skript du ikke forstår** — be om forklaringer til logikken er klar.
