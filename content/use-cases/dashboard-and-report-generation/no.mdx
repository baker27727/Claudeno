## Oversikt

Claude Code utmerker seg ved å bygge rapporteringsinfrastruktur—fra engangsanalyseeksporter til gjentakende dashbordsystemer. Enten du trenger en ukentlig PDF for direktører eller et live-dashboard for operasjonelle team, kan Claude Code generere og strukturere resultatet.

## Dashboardtyper

**Statiske HTML-dashboards**: Selvinneholdt HTML-filer med innebygde diagrammer, stil og data. Perfekt for e-postdistribusjon eller arkivering.

**Interaktive dashboards**: Bygget med Python-rammeverk (plotly, streamlit, dash) som lar brukere filtrere, bore ned og utforske.

**Planlagte rapporter**: Automatiserte skript som kjøres på en tidsplan, regenererer funn og leverer resultat via e-post eller fillagring.

**PDF-sammenfattinger for ledelse**: Formaterte dokumenter med nøkkelmålinger, diagrammer og narrative innsikter for gjennomgang av ledelse.

## Bygge ditt første dashboard

### 1. Definer strukturen

Beskriv hva dashbordet ditt skal inneholde:
- Nøkkelmålinger (KPIer, totaler, prosenter)
- Visualiseringer (trender, sammenligninger, distribusjoner)
- Datafilter (etter dato, region, produkt osv.)
- Målgruppe (direktører, operasjoner, analysegruppe)

### 2. Gi eksempeldata

Del en representativ CSV eller databasespørringsutgang slik at Claude Code kan forstå:
- Datakolomner og deres betydning
- Forventet datavolum og oppfriskningsfrekvens
- Eventuelle beregnede felt som trengs

### 3. Anmod om generering

Eksempelprompt:
```
Lag et interaktivt dashboard for Q4-salgsresultatet vårt.
Ved med:
- Total inntekt og mål vs. faktisk
- Salg etter region (pai- eller søylediagram)
- Daglig salgstrend
- De 10 beste produktene etter inntekt
Bruk plotly slik at seere kan holde musen over for detaljer.
Eksporter som en frittstående HTML-fil.
```

## Praktiske eksempler

### Ukentlig salgsrapport (HTML)

Anmodning: "Generer en ukentlig salgsrapport som viser: total inntekt, vekst %, topprodukter, regional oppdeling og et trenddiagram. Eksporter som en formatert HTML-fil med firmafarge."

Claude Code vil:
1. Laste salgsdata fra din database eller CSV
2. Beregne målinger og sammenligninger
3. Lage polerte visualiseringer med matplotlib eller plotly
4. Pakke alt i stilisert HTML
5. Eksportere klar-til-e-post resultat

### Live operasjonsdashboard

Anmodning: "Bygg en Streamlit-app som viser sanntidsordered status, gjennomsnittlig oppfyllelestid, lagernivåer og kundetilfredshetsprosenter. Oppfrisk hvert 5. minutt."

Claude Code vil:
1. Koble til datakilden din
2. Lage interaktive filtre og KPI-kort
3. Bygge et responsivt oppsett
4. Sette opp mekanisme for automatisk oppfrisking

### Ledelsens månedlige sammenfatning (PDF)

Anmodning: "Lag en PDF-rapport med: ledelsessammenfatning, nøkkelresultater vs. mål, visualiseringer av trender og innsikter/anbefalinger. Inkluder merkevareutstyr."

Claude Code vil:
1. Samle månedlige data
2. Beregne avvik og høydepunkter
3. Generere diagrammer og tabeller
4. Komponere narrative innsikter
5. Formatere som et merkevareutstyr PDF-dokument

## Eksportformater

**HTML**: Frittstående, innebyggbar, full stilkontroll. Best for nett og e-post.

**Excel**: Multi-ark arbeidsbøker med formatering, formler og betinget uthevet. Kjent for forretningsbrukere.

**PDF**: Profesjonell, trykkeklar, fast layout. Ideell for arkiver og lederdistribusjon.

**CSV/JSON**: Rådata-eksporter for import til andre systemer eller BI-verktøy.

## Integrasjon med planlegging

Når Claude Code har opprettet rapporteringsskriptet ditt:

1. **Lagre Python-skriptet** i prosjektmappen din
2. **Test det lokalt** for å sikre at det kjører rent
3. **Planlegg det** ved å bruke:
   - **Linux/Mac**: cron-jobber (`crontab -e`)
   - **Windows**: Oppgaveplanlægger
   - **Sky**: AWS Lambda, Google Cloud Functions, Azure Functions
   - **BI-verktøy**: Tableau, Power BI, Looker (som kan kjøre Python)

Eksempel cron for en daglig 8:00-rapport:
```
0 8 * * * /usr/bin/python3 /home/user/scripts/daily_report.py
```

## Tips for profesjonelle rapporter

**Bruk konsistent merkevareutstyr**: Be Claude Code om å anvende firmafarge, skrifter og logoer.

**Inkluder kontekst**: Legg til datoperioder, datakilder og oppdateringsfrekvens i rapportene dine.

**Fremhev unntak**: Bruk farge og formatering for å trekke oppmerksomhet til viktige avvik eller prestasjoner.

**Skriv for publikum ditt**: Executive summaries skiller seg fra detaljerte analytikerrapporter. Spesifiser publikummet når du ber om rapporter.

**Versjon og arkiv**: Behold kopier av genererte rapporter for historisk sammenligning og revisjonslogg.
