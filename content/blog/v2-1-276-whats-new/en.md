Version 2.1.276 fixes a 2.1.275 regression where requests failed with a 400 error when ANTHROPIC_BASE_URL pointed to a proxy or gateway. This release also includes numerous improvements to artifact handling, memory management, plugin deployment, and VS Code integration—including better support for screen readers, improved session resumption, and enhanced permission and workflow management.
