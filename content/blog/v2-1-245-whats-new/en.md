Added `/status` lines for GitHub connection status, skipped sources, and `managed` markers for authenticated MCP/plugin connectors. Fixed multiple issues with MCP servers, auto mode, `/model` picker, `/resume`, sessions, messaging, UI rendering, spellcheck, and more.
