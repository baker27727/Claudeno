Version 2.1.278 introduces AGENTS.md support for project instructions on Anthropic API and Enterprise Claude Code, allowing Claude to read AGENTS.md instead of CLAUDE.md when no CLAUDE.md exists in the project. Additionally, auto mode now defaults to the server-side classifier on Claude API, Enterprise, Bedrock, Vertex, Foundry and gateways, eliminating classifier overhead charges.
