Auto mode now defaults to server-side classifier on Claude API and Enterprise users (and on Bedrock, Vertex, Foundry, and gateways), eliminating classifier overhead charges. The /status command now shows an 'Auto mode server' row indicating whether this session's classifier runs on the server.
