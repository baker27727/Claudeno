Versjon 2.1.278 introduserer AGENTS.md-støtte for prosjektinstruksjoner på Anthropic API og Enterprise Claude Code, slik at Claude kan lese AGENTS.md i stedet for CLAUDE.md når ingen CLAUDE.md finnes i prosjektet. I tillegg bruker auto-modus nå som standard klassifisereren på serveren på Claude API, Enterprise, Bedrock, Vertex, Foundry og gateways, noe som eliminerer gebyrene for klassifiserer-overhead.
