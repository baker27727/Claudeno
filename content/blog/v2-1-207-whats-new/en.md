Auto mode is now available by default on Bedrock, Vertex AI, and Foundry (disable via `disableAutoMode` in settings). Fixed multiple issues including terminal responsiveness with long outputs, auto-updater conflicts with custom launchers, transcript scrolling glitches, and security issues with malformed glob patterns and shell injection vulnerabilities in plugin hooks.
