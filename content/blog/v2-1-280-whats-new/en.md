Claude Code 2.1.280 introduces Claude Opus 5.5 as the new default Opus model with 1M context and improved pricing. This release includes expanded mouse support for fullscreen mode, new environment variable `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH` to customize MCP tool descriptions, and numerous critical fixes for auto mode stability, dialog navigation, prompt caching in forked subagents, and background session reliability. Improvements to `/permissions` focus handling and OpenTelemetry event reporting provide better administrative control and debugging capabilities.
