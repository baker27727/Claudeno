Version 2.1.222 brings critical security and isolation improvements: worktree-isolated sessions now prevent destructive git commands, auto-mode permission checks now evaluate SendMessage dispatch, PreToolUse hooks no longer bypass tool restrictions, and the startup connectivity check works reliably behind HTTPS proxies. Multiple usage, session, and display fixes improve accuracy of credit attribution, PR linking, and subagent effort reporting.
