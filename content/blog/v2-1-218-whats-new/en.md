Version 2.1.218 introduces background subagent processing for `/code-review` and new spawn caps for subagent delegation, along with improvements to `/ultrareview` error handling and screen reader accessibility. Added `sandbox.filesystem.disabled` setting and emoji shortcode autocomplete. Fixed multiple bugs including Windows path corruption, stale token reporting, and multi-line paste handling.
