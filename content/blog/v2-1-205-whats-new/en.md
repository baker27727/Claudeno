Claude Code now includes an auto mode rule that blocks tampering with session transcript files. The /doctor command is a full setup checkup that can diagnose and fix issues (with /checkup as an alias). Numerous fixes address background agent stability, session linking, worktree handling, and the agent view display. Binary downloads now stream to disk instead of buffering in memory, reducing peak memory usage.
