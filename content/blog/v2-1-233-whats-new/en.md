Version 2.1.233 adds GitLab merge request URL support to --worktree and claude agents view, introduces opt-in user identity forwarding for apps gateways, adds memory and cache TTL configuration for Bash tools and WebFetch, improves screen reader mode accessibility, and fixes issues with MCP v2 streams, permission prompts, CPU usage on Linux, skill command shadowing, argument substitution, Windows path validation, and Bash permission checks.
