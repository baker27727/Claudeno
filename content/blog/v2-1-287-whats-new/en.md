Version 2.1.287 introduces Claude Mods for deeper session behavior customization, including a built-in "You should know" mod. New features include session-name filtering in the agents view, URL prompts from MCP servers, and screen reader accessibility improvements. Multiple fixes address remote sessions, MCP tool handling, file delivery, and hook configuration.
