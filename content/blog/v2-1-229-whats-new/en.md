Claude Code 2.1.229 adds `claude remote-control --continue` for resuming sessions, extends hook support to self-hosted runners, improves security by requiring explicit confirmation for dangerous git commands in `/commit-push-pr`, and fixes multiple issues including streaming response display, tool call crashes, terminal rendering in narrow windows, file path handling on Windows, MCP OAuth, Remote Control UI, GitHub workflow completion, performance stalls, plugin cleanup, workflow CPU limits, file-watcher leaks, SDK/stream-json errors, conversation compaction, OpenTelemetry export, managed-MCP server handling, Git Credential Manager timeouts, and more.
