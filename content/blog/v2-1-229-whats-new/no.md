Claude Code 2.1.229 legger til `claude remote-control --continue` for å gjenoppta økter, utvider hook-støtte til self-hosted runners, forbedrer sikkerhet ved å kreve eksplisitt bekreftelse for farlige git-kommandoer i `/commit-push-pr`, og fikser flere problemer inkludert visning av streaming-respons, verktøy-kall-krasj, terminalrendering i smale vinduer, filstisøkning på Windows, MCP OAuth, Remote Control-brukergrensesnitt, GitHub-arbeidsflyt-fullføring, ytelseslammer, plugin-opprydding, arbeidsflyt-CPU-grenser, filovervåking-lekkasjer, SDK/stream-json-feil, samtalekomprimering, OpenTelemetry-eksport, administrert MCP-serverhåndtering, Git Credential Manager-tidsavbrudd og mer.
