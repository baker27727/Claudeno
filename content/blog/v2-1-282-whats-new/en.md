Added maxProseWidth setting to control prose width in wide terminals. Fixed managed settings parsing to preserve valid settings when one nested value is invalid. Fixed Bash permission rules with mid-pattern `:*` now working from all sources. Fixed requests failing when conversation history contains web search results the API cannot decrypt. Improved error messages for session resumption failures and model-switch scenarios.
