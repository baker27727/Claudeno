Slash command changes: `/fork` now creates background sessions, `/resume` opens a session picker, `/subtask` replaces inline subagent launching. New controls: `claude auto-mode reset`, WebSearch rate limiting, MCP auto-background tool handling, per-session subagent spawn caps. Numerous bug fixes including plan mode permission prompts, symlink worktree creation, shell mode autocomplete, `/ultrareview` branch handling, hosted session startup, and streaming-mode request tracking.
