Claude Code 2.1.261 adds new settings for controlling command output inline limits, a file-based subagent system prompt flag, and `/skill-doctor` for auditing skill costs. Word-editing keys now follow Bash conventions consistently. Organization policy feedback on `/status` explains why policies fail to load. Numerous fixes address session state, Remote Control, cloud sessions, file operations, and permission rules.
