Claude Sonnet 5.5 is now the default Sonnet model with 1M context window. Added new keybinding actions for effort slider control and /mcp reconnect all for managing MCP servers. /rate-limit-options is now discoverable in /help and the command menu. Improved error handling for damaged response streams and overloaded servers. Fixed session unavailability messages to show helpful model-unavailable notices. Enhanced auto mode with a 'Yes, but ask again next time' option for read confirmations. Dollar amounts now display in usage limits across the gateway. Improved artifact pages and plugin configuration screens.
