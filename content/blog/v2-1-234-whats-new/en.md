Added optional CLAUDE_CODE_PROJECT_DIR_NAME environment variable for per-project transcript directory naming. Added selection:clear keybinding action. Added GitLab merge request badge support. Sessions now auto-continue when usage limits reset (configurable in /config). Improved session email handling and security hardening for Windows NT-namespace paths. Fixed numerous session restoration, permission prompt, markdown rendering, and shell command handling issues.
