New managed settings `availableModelsMatch` and `deniedModels` provide finer control over model access. MCP tool outputs now log to OpenTelemetry when `OTEL_LOG_TOOL_CONTENT=1`. New `/doctor prompt-audit` command audits prompts for older-model patterns. Many bug fixes across plugins, MCP servers, permissions, vim mode, and cross-session messaging.
