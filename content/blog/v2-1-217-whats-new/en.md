Claude Code 2.1.217 adds emoji shortcode autocomplete, improves transcript write warnings, fixes memory leaks in tool truncation, resolves Windows auto-update issues, and introduces spawn caps for subagents to prevent unbounded delegation. Screen reader mode stability improvements, remote session reliability fixes, and proper enforcement of corporate security settings (mTLS, TLS-verify, OAuth, proxy) are also included.
